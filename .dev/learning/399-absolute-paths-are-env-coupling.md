# 399 — 저장 자산 속 절대경로 = 환경 결합(팀 이식 부채)

## 맥락
팀 전환 탈개인화(스펙 423) 중 발견 — 추적 파일 47개에 개인 환경 절대경로 ~1,200회:
① codex/서브에이전트 리뷰 출력(.dev/reviews)의 file:line 인용이 절대경로 그대로
② 브라우저 스크립트 OUT 기본값이 세션 스크래치패드(/private/tmp/claude-…) 하드코딩
③ 유저스코프 메모리 경로 인용. 개발자 지적: "유저스코프 메모리·/private 폴더까지 — 난리".

## 근인
산출물을 저장소에 **저장하는 시점**에 경로 정규화 관문이 없었다. codex는 절대경로로 인용하고,
스크립트는 "지금 세션의 스크래치패드"를 기본값으로 굳혔다 — 각자 그 순간엔 동작하지만
저장되는 순간 환경 결합이 자산에 박제된다.

## 처방(재발 방지 규칙)
- **저장 관문에서 상대화**: 리뷰 출력·스크립트를 저장소에 넣을 때 레포 절대경로→상대경로,
  홈 하위→`~`, 세션 스크래치패드는 저장 금지(레포 상대 out 디렉터리로).
- 스크립트 기본값은 **레포 상대 + env 오버라이드**(`process.env.OUT ?? 'tests/browser/out-tmp'`).
- 점검 1줄: `git ls-files | xargs grep -l '/Users/\|/private/tmp'` = 0 유지.
