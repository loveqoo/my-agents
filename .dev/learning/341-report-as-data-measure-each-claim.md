# 341 — 남의 에이전트 리포트는 "데이터": 주장마다 따로 실측하라

## 상황

회사 디바이스에서 사내 CA(스펙 339·340)를 붙였는데도 위키 검색이 503. 그 디바이스의 에이전트가
진단 리포트를 만들었고, 사용자가 **사진으로 전달**했다. 리포트는 `served_mcp.py` 2곳 수정을
제안했다: (a) `_FETCH_UA = "curl/8.7.1"`, (b) httpx.Client에 `http1=True, http2=False`.
근거: "SASE 게이트웨이가 `curl/` 접두 UA + HTTP/1.1만 통과. Python httpx 기본값(HTTP/2 + 커스텀
UA)은 /login/으로 리다이렉트되어 503."

## 배운 것

### 1. 그럴듯한 진단은 **맞는 처방과 무동작 처방을 한 묶음**으로 판다

한 줄 실측이 갈랐다:

```python
r = httpx.get("https://ko.wikipedia.org/w/api.php", ...)
print(r.http_version)   # → HTTP/1.1
```

httpx는 `http2=True`를 **명시해야만** HTTP/2를 쓴다(h2 패키지가 깔려 있어도 기본은 1.1). 즉 (b)는
현 코드에서 **아무것도 바꾸지 않는다**. 리포트의 근거 문장("httpx 기본값=HTTP/2")이 틀렸고,
그 틀린 전제가 옳은 결론(UA) 옆에 나란히 앉아 있었다. 리포트를 통째로 채택했다면 무동작 코드
2줄이 "이게 회사망을 통과시킨 이유"라는 잘못된 인과와 함께 영구히 남았을 것이다.

**교훈**: 리포트의 *결론*이 맞아 보여도 *주장 단위로* 쪼개 각각 측정한다. 번들로 삼키지 않는다.

### 2. 환경 고유값은 소스가 아니라 env

`curl/8.7.1` 하드코딩은 세 가지가 틀렸다: ① 위키 UA 정책(식별 가능한 UA 요구)에 역행, ② 이 맥·
다른 배포에는 무의미한 **한 회사망의 규칙을 전 배포 기본값으로** 강제, ③ SASE 정책 우회를
소스 계약으로 승격. → `WEB_FETCH_UA` env(기본값 무변경). 사내 CA(339·340)와 **같은 형태의
처방**이다 — "그 환경만 아는 값은 그 환경의 `.env`에".

### 3. 검증은 와이어에서 — `_fetch_ua()`가 맞는 값을 리턴한다 ≠ 그 값이 나간다

로컬 에코 서버를 띄워 `_wiki_get`을 태우고 **서버가 관측한 User-Agent**를 단언했다(V3). 덤으로
같은 호출이 SSRF 호스트 재검증에 걸려 차단되는 것도 확인(V4) — 가드 무회귀를 공짜로 얻었다.
헬퍼 리턴값만 단언했으면 "헤더에 안 실림" 같은 배관 결함을 못 잡는다(installed ≠ covering).

### 4. env가 헤더로 나가면 주입을 한 번 본다

`WEB_FETCH_UA="curl/8.7.1\r\nX-Injected: 1"` → httpx가 `Illegal header value`로 거부, 도구는
graceful `{'error': …}`. 값이 운영자 env라 위험은 낮지만, **확인 비용이 한 줄**이면 확인한다.

## 결과 (2026-07-14)

회사 디바이스에서 `WEB_FETCH_UA=curl/8.7.1` 한 줄로 **위키 검색 동작**(사용자: "잘 됩니다").
리포트의 진단(UA 필터)은 옳았고, 리포트의 근거(HTTP/2)와 처방 형태(하드코딩)는 틀렸다 —
**결론이 맞아도 근거와 형태는 따로 검증해야 한다**는 것의 실사례.

단, CA(339/340)와 UA(341)를 **둘 다 켠 채** 성공했으므로 CA 단독 필요 여부는 갈리지 않았다.
동작하는 환경을 흔들 이유가 없어 미분리로 종결 — "재현 불가 환경에서는 성공의 원인도 완전히
분해되지 않는다"를 그대로 기록해 둔다(추측으로 메우지 않는다).

## 처방(재사용)

- 외부(사람·타 에이전트)가 준 진단은 **관측 데이터**로 취급 — 주장→실측→채택/기각 표를 스펙에 남긴다
  (341 "리포트 검증" 표). 기각도 근거와 함께 남겨야 다음에 같은 제안이 또 오지 않는다.
- 재현 불가 환경(회사망)의 처방은 **재현 가능한 부분만 이 맥에서 핀**하고(UA가 실제로 나간다·
  가드 유지·기본값 무회귀), 최종 확인은 정직하게 "사용자 실측 대기"로 남긴다.
