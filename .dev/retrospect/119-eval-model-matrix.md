## 잘된 것
- **설정 만회 함정 선제 차단**: _load_context는 미존재 모델명을 기본 모델로 만회 —
  사전 검증 없으면 "다른 모델로 조용히 시험"(스펙 089와 동류). 레지스트리 대조 400.
- codex 3건: 부분 그룹(최근 50 컷) → 그룹 전량 재조회 / 1개 모델=단순 오버라이드 런 /
  **오버라이드 범위의 정직한 경계를 UI 힌트로**(조율형은 메인 모델만 교체 — 위임 대상은 그대로).
- e2e(fast-worker)가 **시나리오 가정의 오류를 실측으로 반증하고 스스로 교정**: trace_has("rag:")로
  모델 분기를 기대했으나 조율형 위임 선정은 어휘 겹침 기반 순수 결정 로직이라 모델 축과 독립 —
  구조적으로 영구 불변임을 코드로 추적. output_contains(실측 재현 확인된 마커)로 교체해
  진짜 결정적 분기 확보(mock은 고정 템플릿이라 원천 불가).

## 배운 것 (평가 설계 원칙)
- **채점 기준은 "무엇이 그 축에 민감한가"를 따라 골라야 한다**: 조율형에서 도구 흔적은
  위임 로직(결정적)의 신호, 출력 내용은 모델의 신호. 모델 격자에는 출력/judge 기준이 유효.
- 위임 e2e의 가정("모델 바꾸면 도구 사용 갈림")처럼 그럴듯한 인과는 **한 번 실측**으로 확인.
