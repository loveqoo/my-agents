## 잘된 것

- **게이트 사다리가 각자 다른 결함을 잡았다(비겹침 실증).** 스위트(행위)·codex(등가성 여집합)·
  radon(구조)이 다 초록인 상태에서 **mypy가 진짜 회귀를 적발**: Phase 2의 ARG 개명이
  keyword-only `run_id` 3곳을 건드려 배치 작업이 키워드 호출 TypeError로 죽는 상태였다.
  스위트는 배치 경로를 안 지나고, ruff는 개명 후가 "올바른" 코드고, 오직 타입체커만 호출-시그니처
  정합을 본다. 도입 첫 판에 값을 했다.
- **지시서에 "고치지 말고 보고" 원칙을 박은 것.** Phase 4 위임자가 rag.py의 실버그(인제스트 실패
  처리 중 동시 삭제 레이스 → None → 500)를 수리 대신 보고했고, 판정(404 정직 거절)은 메인이 했다.
  위임자의 가장 가치 있는 산출물이 "발견"이 되도록 인센티브를 설계하는 것 — 추측 수리 금지.
- **관심사 지도 선행(분석≠실행 분리).** 분할 4건 모두 deep-reasoner/메인이 지도(그룹·의존 방향·
  재수출 전수·전역 상태·CC 이음새)를 먼저 박제하고 실행자는 지도대로만. 지도의 전제 오류
  (_agent_a2a_skills 소재 혼동)를 분석자가 실측으로 교정해 실행 단계 오류를 예방.
- **측정 기반 마감이 자가선언을 대체.** vars() diff 여집합 0·라우트 수 전후 동일·공유 전역 is
  동일성·차등 실행 배터리(39케이스)·getsource 계약 보존 — 전부 명령 출력으로 보고받았다.

## 배운 것

- **차등 판정의 기준점은 "스펙 시작 전 커밋"이어야 한다.** verify_038 실패를 stash 차등으로
  "기존 부채"라 오분류했다 — stash는 미커밋만 걷어내고, 이미 커밋된 Phase 2 회귀는 양쪽에 남아
  "전후 동일 실패"로 보였다. 재검증은 291 이전 커밋 worktree로 했고 038=회귀·036/056=진짜 부채로
  갈렸다. **"전후 동일하니 무관"은 기준점이 오염을 공유하면 거짓이 된다.**
- **개명 안전성은 "위치 호출 여부"만으론 못 판정한다 — keyword-only(`*` 뒤)는 이름이 곧 계약.**
  ARG 개명 지시서가 "호출부 전부 위치 인자 확인"을 걸었지만 `*, run_id=None`은 구조적으로
  키워드 호출뿐이라 그 검증 자체가 성립 안 되는 자리였다. 파라미터 개명 전 체크: ① 위치 호출?
  ② keyword-only? ③ **kwargs 통과? — ②③은 이름이 API다.
- **스위트 실행 중 worktree를 흔들지 마라.** 지연 import가 stash 창에 걸리면 신구 혼합 검증이
  된다. 이번엔 깨끗한 단일 트리 재실행으로 봉합했지만, 규칙은 "게이트 실행 중 트리 불변".
- **파사드 분할의 알려진 경계**: 모듈 전역 재할당(monkeypatch)은 분할 모듈에 늦은 바인딩되지
  않는다(codex Low). 실사용 0 확인 후 미문서 경계로 백로그 기록 — 고침도 기각도 아닌 정직화.
