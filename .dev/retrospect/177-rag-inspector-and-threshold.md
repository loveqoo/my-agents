# 회고 177 — RAG 인스펙터 가독성 + 컬렉션별 유사도 임계값 (스펙 191)

## 무엇을 했나
실사용 문의 3건(문서검색 결과가 벽 텍스트라 불편 / "유사도 낮음" 기준 불명 / 검색어가 안 보임)을
받아 인스펙터 RAG 표시를 히트별 카드(컬렉션·파일명·점수 배지·본문 접기)+척도 범례+검색어로 개선하고,
**컬렉션별** 최소 유사도 필터를 추가(에이전트 폼에서 컬렉션마다 슬라이더). 단위+e2e(15/15)+codex 적대검토
+무회귀 초록.

## 배운 것

### 1. "1개 값"이 "per-X"로 바뀔 때 질문은 "각 단위가 X를 이고 있나"
에이전트당 임계값 1개로 다 짜고 검증까지 끝냈는데, 사용자가 "Rag(컬렉션)**마다** 지정"을 추가 요구했다.
피벗의 핵심은 UI 슬라이더 여러 개가 아니라 **데이터 모델**이었다 — 검색 코어(`search_collections`)가
여러 컬렉션 히트를 **병합하며 컬렉션 출처를 버렸다**. per-collection 필터는 각 히트가 "어느 컬렉션에서
왔나"를 알아야 하므로, 히트에 `collection` 태깅을 다시 심어야 했다. **교훈: "하나의 값"을 설계할 때
"이게 per-X로 번질 수 있나? 그럼 각 결과 단위가 X를 이고 있나?"를 먼저 묻는다. 병합 지점에서 버린
출처는 나중에 per-X가 필요하면 되살려야 한다.** (커밋 전이라 피벗은 깨끗했다 — [[compounding-ends-with-commit]]
per-spec 커밋 규율의 반대 이점: 미커밋이라 재설계 자유)

### 2. 적대 리뷰는 "새 것을 지켰지만 옆의 옛 것이 샌다"를 짚는다
내가 **새로 추가한** hitsDetail.textPreview는 비밀 마스킹(_sanitize)했다. 그런데 codex는 같은 sink
표면의 **기존** `result` 필드가 `_cap`만(마스킹 없음)이라 문서 본문 내 비밀이 새는 **비대칭**을 짚었다.
내 주의는 내가 만든 필드에 쏠려 옆의 형제 필드를 못 봤다 — 적대자는 정확히 그 여집합("보호한 것 옆에
안 보호한 것")을 본다. **교훈: 마스킹 필드를 추가할 땐 같은 표면의 형제 필드도 같은 보장을 받는지
확인한다. 일관성 틈이 누출이 숨는 곳이다.** 봉합=`_sanitize_preview` 단일 경로로 셋(직접 result·
브로커 resultPreview·hitsDetail) 통일(drift 0). ([[installed-guard-isnt-covering-guard]]·
[[adversarial-review-before-destructive-ship]]의 재연 — 이번엔 "가드 설치 위치≠부수효과 위치"가 아니라
"마스킹 적용 필드≠같은 표면의 형제 필드")

### 3. 기존 실패를 내 변경 탓으로 (혹은 반대로) 넘겨짚지 말고 격리하라
RAG 무회귀 4개(072/103/037/130)가 빨갰다. "내가 search_collections 시그니처를 바꿔서?"로 단정하기
쉬웠지만, `git stash`로 내 백엔드 변경만 격리해 돌리니 **똑같이 실패** → 기존 인프라 이슈(컬렉션 생성
400·라이브 Obsidian 전제)로 확정. 내 변경은 결백. **교훈: 여러 테스트가 빨가면 "내 diff 때문"과
"원래 그랬음"을 stash 격리로 가른다. 넘겨짚으면 멀쩡한 코드를 헛고치거나 진짜 회귀를 기존 탓으로 묻는다.**
([[probe-deeper-before-concluding]] 측정 우선)

### 4. 결정적 e2e가 막히면 mock의 기존 트리거 장치를 확장한다
mock-llm은 search_documents tool_call을 안 냈다(delete_record만) → RAG 경로를 브라우저로 실검증
불가였다. 새 mock을 짜는 대신 **기존 스펙-179 dev-트리거 테이블**(`_TOOL_TRIGGERS`)에 한 줄 추가해
"검색/문서" 키워드→search_documents를 결정적으로 내게 했다. 작은 테스트-인프라 투자로 폼→필터→인스펙터
카드 전 경로 실검증이 열렸다. **교훈: 경로가 결정적으로 안 돌면 우회 mock 말고 기존 결정적-트리거
기구를 확장하라 — 실 경로를 그대로 태운다.**
