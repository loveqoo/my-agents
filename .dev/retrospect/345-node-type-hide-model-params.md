# 345 — 노드형 세부 탭 모델 파라미터 숨김(스펙 417)

## 발단
개발자: "노드형 에이전트 수정에서 세부 탭에서 모델 메타값 설정은 이상하다. 노드마다 셋팅했으니까."
관찰 한 줄이 UI 불일치를 정확히 짚었다.

## 진단 — 표면 짝이 반쪽만 숨겨져 있었다
노드형(pipeline)은 에이전트-레벨 모델 **선택**을 이미 숨긴다(AgentForm 566행 `isPipeline ? null`,
"모델·프롬프트도 노드마다"). 각 노드가 자기 모델을 고른다. 그런데 세부 탭의 모델 **파라미터**
오버라이드는 안 숨겼다 — **선택할 수도 없는 모델의 파라미터**를 노출. 짝(모델 선택 ↔ 그 파라미터)
중 하나만 숨긴 [[hidden-value-reappears-in-summary]]의 변종. 스펙 263이 요약 카드에선 이미 정렬했는데
세부 탭 패널은 빠뜨렸던 것.

## 배운 것

### 1. "표면을 숨기면 짝과 데이터·모든 소비 표면을 함께" — 전수해야 완성
스펙 263이 노드형 요약을 "노드마다 설정"으로 바꿨지만, 같은 논리가 적용될 **세부 탭 패널**은
안 건드렸다. 표면 하나를 숨길 땐 그 데이터가 흐르는 소비 표면을 grep 전수해야 한다([[retrospect 261
single-source-sweep]]). 이번엔 소비 표면이 셋(세부 패널·요약 카드·저장 페이로드)이었고 263이 요약만
정렬 → 세부 패널·저장이 남았다.

### 2. 패널만 숨기면 값이 캐스케이드로 **조용히 적용**된다(238 핵심)
UI에서 패널을 `!isPipeline`로 숨기는 것만으론 부족 — `form.modelParams`가 남아 저장되면 캐스케이드
(모델기본→**에이전트**→노드→세션)로 **전 노드에 조용히 적용**된다. 숨긴 값의 비가시 적용이 정확히
[[hidden-value-reappears-in-summary]]가 경고한 함정. finalizeForm 노드형 분기에 `modelParams: {}`를
더해 저장서도 비웠다(레거시 값도 다음 저장서 청소). **숨김의 짝은 UI 게이팅 + 데이터 제거 둘 다.**

### 3. 모델-의존 표면과 모델-독립 표면을 갈라야 정합
같은 "모델 동작" 구획의 단기 기억은 **유지**했다 — 대화 창 깊이(숫자)는 모델과 무관해 에이전트-레벨
기본값이 정합(노드형 상속 원천). 반면 모델 파라미터는 능력/기본값 해석에 **모델이 필요**한데 그 모델이
숨겨져 있어 부정합. 유형별 숨김 판정은 "이 설정이 (숨긴) 모델에 의존하는가"로 — 구획 통째가 아니라
필드 단위 판정([[weight-decides-placement]] 결).

### 4. 위저드 UI 검증은 실 네비게이션 관용구를 먼저 읽어야
브라우저 검증서 목록 행 편집(연필=first 버튼, 삭제=last **금지**)·취소 후 상세 드로워 복귀·"에이전트
목록" 브레드크럼 등 관용구를 몰라 3회 헛디뎠다. [[retrospect 233 nearest-sibling-idiom]] — 구동 스크립트는
기존 것의 네비게이션을 먼저 읽고 계승했어야. suite-* 픽스처가 목록 필터 밖이라 실재 노드형
(research-pipeline-demo)으로 전환한 것도 "화면에 실제 보이는 것"을 먼저 확인했어야 할 지점.
