# 261 — 스펙 286(에이전트 상세 화면 정비) 회고

## 무엇을 했나
스샷 검토로 발견한 버그 2(구성 카운트=서버 수·헤더 typeLabel 로컬 사본의 내부 키 노출)+정리 3
(헤더 배지 슬림화·노드 요약·어휘)을 한 스펙으로. 사용자 승인("시작하시죠") 후 전체 정합 기준
(whole-fix)으로 신호등 단일 출처화까지 확대.

## 배운 것

1. **로컬 사본은 신설 키에서 어긋난다 — 283이 typeLabel을 단일 출처로 export했는데 상세 페이지는
   여전히 로컬 계산본을 갖고 있었다.** 로컬 사본은 작성 당시(직접/조율/산출물)엔 옳았지만 pipeline
   (259)이 신설되자 fallback이 내부 키를 그대로 노출했다. 264의 "미러는 변경 시 함께"와 같은 계열:
   단일 출처를 만들었으면 **기존 사본을 전수 교체**해야 완성이다(export만으로는 절반). 같은 패턴을
   신호등(284 인라인 LIGHT)에서 반복 발견 → AGENT_STATUS로 승격하며 대시보드 StatusPill 색까지 통일.

2. **파생값 카운트는 진실원 교체 시 함께 죽는다.** "도구 N"이 `mcps.length`(서버 합집합)를 세고
   있었다 — 276이 진실원을 tools(도구 단위)로 바꿨을 때 폼·런타임은 갱신했지만 상세 표시는 노후.
   스키마 축이 바뀌면 그 축을 **표시하는 모든 표면**을 grep해야 한다(이번엔 스샷 검토가 잡았지만
   운이었다).

3. **육안 페어가 또 잡았다(133 계열)**: e2e 18/18 GREEN 뒤 스샷에서 노드형 "연결 없음: 문서 · 도구"
   — 단언하지 않은 표면의 의미 오류(노드형은 도구가 노드 소유라 부재=정상)는 기계 단언이 못 잡는다.
   기능 검증 후 스샷 1회는 비용 대비 수확이 꾸준히 있다.

## 후속(개요 압축 + 어휘 5+2 지시)에서 배운 것
- **오래 안 돌린 shot-* e2e는 침묵 노후 더미가 된다**: 154는 148(이름)·245(풀페이지)·246(탭)·
  284(탭 분리)·목록 성장(페이지네이션) 다섯 겹으로 깨져 있었고, 156도 섹션명 개칭으로 깨져 있었다 —
  전부 이번 문구 변경과 무관한 선행 노후. verify-*는 스펙마다 돌지만 shot-*는 아무도 안 돌려서
  깨짐이 축적된다. 표면을 바꾸는 스펙이 그 표면의 e2e를 grep해 같은 턴에 갱신하는 규율(283/284는
  지켰다)이 없던 시절 스크립트들이 부채로 남은 것.
- 어휘 교체(private→비공개)는 **표시 문자열만** — owner_id 판정·API payload는 무변경이라 게이트
  무영향. 죽은 소비자(OwnerTag)는 번역이 아니라 삭제가 정답.

## 후속 2(군더더기 라운드)에서 배운 것
- **조용한 폴백은 오식별을 침묵시킨다**: 아이콘 레지스트리의 `MAP[name] || Appstore` 폴백 때문에
  미등록 이름(arrow-left)이 에러 없이 엉뚱한 그리드로 그려졌고, 사용자가 발견했다. 전수 측정
  스크립트(사용 이름−등록 키 차집합)로 같은 계열 4건이 더 나옴 — 폴백이 있는 매핑은 차집합 측정이
  유일한 검출 수단(빌드·tsc·e2e 전부 초록).
- **문구 다이어트의 원리**: 기호가 이미 말하는 것(색·상태)을 글자로 반복하지 않는다. "파랑=온라인"의
  '파랑='은 파란 점 옆에선 중복. 안내문은 행동 하나만("공개로 전환하면 켤 수 있습니다") — 상태 서술
  ("꺼짐 · 비공개에서는 불가")은 스위치·컨텍스트가 이미 보여준다. copy-rubric에 유형 6으로 등재 후보.
- 정보의 **자리(ownership)**: "비공개(A2A 불가)"처럼 남의 행에 얹힌 제약은 그 제약이 사는 행(A2A)으로
  옮기면 두 행 다 짧아진다.

## 아쉬운 것
- 스펙 완료 조건 4의 "상세 화면 내 '메모리' 문자열 0"을 전 페이지 텍스트로 단언하려다 좌측 네비의
  '메모리' 메뉴명과 충돌할 뻔 — 어휘 단언은 스코프(해당 Descriptions)로 좁혀 해결. 어휘 통일이
  화면 단위로 진행되면 이런 반쪽 상태(네비=메모리, 상세=기억)가 남는다. 네비 메뉴명 통일은 별도
  판단(백로그 후보).
