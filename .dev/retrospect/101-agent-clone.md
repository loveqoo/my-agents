# 101 — 에이전트 복제 (스펙 120)

## 무엇을

저마찰 재사용 = "이거랑 비슷한 거 하나 더". `POST /agents/{id}/clone` + 상세 드로어 복제 버튼. 방향 4
(4개 방향 "모두 차례대로") 4번(마지막). 사용자 선택 "복제".

## 어떻게

- 백엔드: 원본 config를 새 ui 초안으로 복사(card 제거)·복제자 소유 스탬프·미존재 404-fold·관리 권한 불요.
- 프론트: cloneAgent + 복제 버튼을 can_manage 게이트 **밖**에 ui/code/external 3 드로어 모두.

## 잘된 것

- **새 동사를 use/manage 축에 먼저 놓음**(learning 120 ①): 복제=읽기+새 생성→원본 관리 권한 불요·가시하면
  복제→백엔드 assert_may_manage 안 걸고 프론트 버튼을 can_manage 밖에(비소유 공유 에이전트도 복제=재사용
  핵심). 삭제 옆이라 습관적으로 can_manage로 감싸는 실수를 피함(동사마다 축 재판정).
- **생성형 소유권 스탬프**(120 ②): 복제자 소유(069 승계 금지) — "내 복제본 내가 관리 못 함" 모순 방지.
- **복사 범위를 행위로 좁힘**(120 ③): card 제거·endpoint/token은 애초 별도 컬럼이라 미복사→안전한 ui 복제본.
- **렌더 변형 전부 배선 + 브라우저 실렌더 확인**(120 ④, 114 사전적용): ui/code/external 3 드로어 모두에
  버튼, shot-clone-120이 렌더+클릭→"(복사본)" 배선 실측·스크린샷으로 푸터 시각 확인. verify_120 HTTP 13/13.

## 배운 것 / 함정

- **새 동사는 use/manage 축 먼저 판정**(120 ①) — 기존 게이트에 습관적으로 묶으면 재사용 막음.
- **생성형 동사는 소유권 새로 스탬프**(120 ②, 승계 금지).
- **복사는 행위 설정만, 등록·비밀 스냅샷 떼어냄**(120 ③).
- **같은 액션 렌더 변형 전부 배선 + 브라우저 확인**(120 ④).
