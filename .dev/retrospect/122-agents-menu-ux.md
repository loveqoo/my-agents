## e2e가 남긴 재사용 지식(스크립트 주석에도 있음)
- antd 아이콘 버튼은 접근성 이름이 "아이콘라벨+텍스트"로 합쳐짐 → exact 매치 금지, 정규식.
- 드로워에 같은 버튼이 두 곳(초안 박스+버전 히스토리) — 스코프 없이 클릭하면 strict 위반.
- 생성 직후 이미 "초안 편집" 라벨(신규=v1 초안) — 문서 예시 아닌 실측 기준.
