# 329 — 오버라이드 모델 None==None 오폭 수리(스펙 401, 소형 루프)

- **버그의 형태**: "소유 판정"을 값 동등(==)으로만 하면 부재끼리도 매칭된다(None==None).
  스펙 290 거절 게이트는 "이 이름이 오버라이드에서 왔는가"를 `overrides.get("model") ==
  model_name`으로 판정 — 둘 다 미지정이면 참이 되어 미지정 에이전트가 400. 처방=실명 요구
  (truthy 가드 1줄). 부재 축이 있는 동등 비교는 항상 "존재+동등"으로.
- **발견 경로가 자산**: 스펙 400 재활 중 verify_122가 이 오폭에 걸렸고, 그때 "테스트 축 분리
  (픽스처에 모델 명시)+실버그 보고"로 갈라둔 것이 이번 스펙의 발단·재료가 됨 — 재활 캠페인의
  "수선하지 않고 보고" 규율이 작동한 사례.
- **codex 스팟(P1 0)**: 여집합에서 빈 문자열 경계(전 400→폴백)가 나옴 — 코드 결함이 아니라
  승인된 시맨틱("빈값=미선언")의 미문서 경계로 판정, B6d 테스트 핀으로 정직화(회고
  complement-attack-can-be-honest-boundary 처방 재사용).
- **그물의 두 무대**: B6 폴백 기대값을 mock-chat으로 하드코딩했다가 db층(라이브 DB — 기본 chat이
  실모델)에서 즉시 깨짐. 그물 대상 테스트의 기대값은 "지금 이 DB의 기본"을 조회해 비교(virgin과
  라이브 둘 다에서 참인 단언만 그물에 넣을 수 있다).
