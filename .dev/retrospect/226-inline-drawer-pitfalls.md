# 회고 226 — 인라인 top 드로어 함정 카탈로그 + 단계형 이식 (스펙 249, 248 후속15~31)

## 무엇을 했나
U 손잡이 오버라이드 서랍(여닫이 은유 완성: ∨/∧ 손잡이·패널 부착·영역 한정) + 서랍 내부를
생성폼 기조(Steps 2단계·하단 고정 푸터·요약 생략)로 개편. 도구 다수(14) 실측까지.

## 배운 것 — antd 인라인 드로어(getContainer=false) 함정 5종 (전부 실측으로 발견)
1. **래퍼 overflow: hidden 필수 짝** — 닫힘=위로 translate라 클리핑 없으면 잔상이 위 요소에 비침.
2. **패널 밖 요소는 pointer-events: auto 명시** — rc-drawer가 wrapper에 none(마스크가 클릭 가로챔,
   elementFromPoint로 확정).
3. **wrapper z를 마스크(1000)보다 위로** — 같은 z면 DOM 뒤의 마스크가 이김.
4. **치수에 vh 금지** — 모바일 주소창 탓에 가시 영역 초과(닫기 푸터 가림). 컨테이너 %가 안전.
5. **destroyOnHidden 없으면 본문 스크롤 잔존** — 재열기 때 이전 스크롤로 열려 상단(Steps) 가림.
   autoFocus도 열림 스크롤 유발 — 끔.

## 배운 것 — 방법
- **"어디서 열리나"는 컨테이너 소속 문제, 은유가 답** — body→우측 영역→헤더 아래 두 번 이사.
  오버레이를 만들 땐 "무엇의 자식인가"를 은유로 먼저 물을 것.
- **시각 효과는 선언이 아니라 이동을 실측** — 닫기 손잡이 호버가 무동작인 채 "됐다" 보고(margin-top이
  bottom 고정에 무효). boundingBox Δy 단언으로 정정.
- **용량 경계는 만들어서 재현** — "도구 많으면?"을 MCP 10개 임시 등록으로 실측(697>519) 후 봉합
  (내부 스크롤 상한). 시드 자동 정리로 오염 없음.
- 요약 게이트는 도구 성격 따라 — 생성(비가역 커밋)=요약 필수, 오버라이드(세션 한정 실험)=생략하고
  적용 상시(사용자 결정).
