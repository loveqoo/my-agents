# 113 — 회고: 플레이그라운드 모바일 컴팩트 헤더 (스펙 132)

## 무엇을 / 왜
플레이그라운드 점검 2탄(사용자): 모바일에서 에이전트/세션/도구 표시가 답답 — "작은 아이콘으로만".
도구 버튼은 이미 compact(lg 미만 아이콘만)였고, 공간을 먹던 건 AgentCombo(이름·모델·페르소나 2줄·
초안 태그)와 SessionCombo(미리보기 텍스트). `iconOnly` prop(isMobile=!md)로 트리거를 아이콘만으로,
드롭다운 너비는 `min(360/300px, 100vw-24px)` 캡(화면 밖 넘침 방지). 데스크톱 무변경.

## 잘된 것
- 기존 compact 축(lg 기준 버튼 라벨 제거)이 있어 **빠진 두 컴포넌트만** 정밀 타격 — 변경 최소.
- 검증을 뷰포트 페어로: 모바일(390×844, 아이콘만+드롭다운 화면 내 boundingBox 판정)+데스크톱
  (1400, 이름/라벨 무회귀) — fast-worker 2회 연속 7/7. 세션 생성 0(헤더 표면만).
- fast-worker가 strict mode violation(heading 중복 매칭)을 banner 스코프로 자가 해결.

## 아쉬운 것 / 리스크
- 모바일 점검은 이제 시작 — 인스펙터/오버라이드 드로어·채팅 영역의 모바일 최적화는 미점검(OUT 명시,
  점검 항목으로 남음).
- iconOnly에서 초안 배지가 숨음 — 모바일에선 초안 여부를 피커 열어야 앎(수용한 트레이드오프).

## 다음 작업 Context에서 상기할 것
- 모바일 UI 검증은 **뷰포트 페어**(모바일 판정 + 데스크톱 무회귀)와 드롭다운/오버레이의
  boundingBox 화면 내 판정을 기본으로.
- 참고: 스펙 132, 회고 112(플레이그라운드 점검 1탄), 메모리 playground-is-precision-debug-channel.

## v2 추기 (사용자 실기기 피드백으로 방향 전환)
v1(아이콘만)을 실폰으로 쓴 사용자: "에이전트 이름이 안 나옴·세션 이름 안 나옴·버튼 뭔지 안 보임 —
여러 줄로 온전한 텍스트로." **v1은 공간을 아꼈지만 식별 정보를 없애 답답함의 종류만 바꿨다.**
v2 = 세로 스택 3줄(에이전트 전체폭 이름·세션 라벨·도구 라벨+줄바꿈), iconOnly→fullWidth, compact는
비모바일 전용으로 한정. 드롭다운 뷰포트 캡은 존치. 재검증 8/8(반전 체크+가로 오버플로 없음+데스크톱
한 줄 무회귀) 2회.

**교훈**: "답답하다 = 작게"가 아니라 "답답하다 = 필요한 게 안 보인다"일 수 있다 — 모바일 축소 요구는
**공간 절약과 식별 정보 보존의 균형**이고, 여러 줄 스택은 정보를 지키면서 푸는 도구다. 사용자 지시의
표면 문구("작은 아이콘으로만")보다 다음 실기기 피드백이 진짜 요구를 드러냈다 — UI 방향 변경은 실기기
확인 사이클을 짧게(1턴 만에 교정된 것이 다행).
