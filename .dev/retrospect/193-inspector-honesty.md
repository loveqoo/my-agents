## 무엇을 했나
전송 프롬프트 재구성→**모델 콜백 실측**(TraceCaptureHandler: on_chat_model_start 메시지·on_llm_end
usage 합산, Langfuse와 병행) · 토큰 글자수÷4 추정→**usage 실측**(부재 시 "추정" 라벨 폴백) · 턴
배지 메시지 인덱스→질문 순번. 실모델 검증 7/7: system 401자(계획·도구 안내 포함)·도구 왕복 6메시지·
호출 3회 병기·토큰 2,978/131 실측·"턴 1".

## 배운 것
1. **표시 계층의 "재구성"은 소스가 다양해지는 순간 거짓이 된다 — 관측은 소비 지점(콜백)에서.**
   131의 재구성은 직접형 하나일 땐 진실이었지만 커스텀 impl(자체 프롬프트)·203 힌트가 생기며 어긋났다.
   모델 콜백에서 실측하니 앞으로 어떤 impl이 생겨도 자동으로 진실 — [[installed-guard-isnt-covering-guard]]
   의 관측판(가드처럼 관측도 부수효과 발생 지점에).
2. **usage는 이미 공짜로 오고 있었다** — qwen(OpenAI 호환)이 usage_metadata를 주는데 안 읽고 추정만
   썼다. "실측이 없어서 추정"이 아니라 "안 읽어서 추정"이었는지 먼저 확인.
3. **접이식 UI 검증 오탐 2연**: defaultOpen 패널을 클릭해 닫고 "안 보인다"(1차), 행별 접힘 본문을
   안 펼치고 "없다"(2차). 접이식 검증은 "지금 열려 있나"를 먼저 확인하고 필요한 행만 펼친다.
