# 회고 194 — 매니페스트 소비 선언 + 폼 게이트 (스펙 206)

## 무엇을 했나
AgentManifest에 `consumes`(읽는 설정 표면 자기선언) 추가·전 impl 선언 → /agent-impls 메타 노출 →
AgentForm이 안 읽는 그룹 숨김+저장 연결 "무시됩니다 N개" 경고(데이터 보존). e2e: route=기억만+경고,
plan_execute=전부(무회귀). 검증 중 모바일 내비 잠김(onSelect 미발화)·감사 NAV 공허 초록 발견·수리.

## 배운 것
1. **"이미 선택된 항목 재클릭"은 onSelect의 사각** — antd Menu onSelect는 선택 변경에만 발화한다.
   기본 뷰=agents라 첫 클릭이 재클릭이 됐고 모바일 드로어가 영영 안 닫혔다(옛 하네스가 백드롭을
   대신 눌러줘 숨어 있던 결함). 항상-발화가 필요한 부수효과(닫기)는 onClick에.
2. **감사 하네스의 실패 분류가 종료코드에 다 반영되는지 확인** — NAV 실패(표면을 열지 못함)가
   exit 0으로 새서 audit-all이 초록이었다. "열지 못한 표면=측정 0건"인데 통과로 세면 커버리지가
   조용히 준다(186 공허 초록·187 커버리지 교훈의 세 번째 변주: 이번엔 집계가 낡음).
3. **게이트 기본값은 "숨김"이 아니라 "노출"** — 선언 깜빡한 impl의 표면이 거짓 소멸하면 "연결했는데
   무시"보다 나쁜 "연결조차 불가"가 된다. 미선언=전부 노출(무회귀)로 두고 선언만 정확 게이트.
