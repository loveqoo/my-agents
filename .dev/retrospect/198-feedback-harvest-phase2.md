# 198 — 피드백 수확(스펙 209 Phase 2): 파이프라인이 실데이터로 닫힘, --reload가 마이그레이션을 반쪽 적용

## 파이프라인이 실데이터로 닫혔다(가장 큰 성과)
Phase 1에서 브라우저로 👍 준 plan-execute-demo 세션("한글 한 줄 요약")이, Phase 2 AgentDetail의 "피드백
수확" 버튼에 **배지 1**로 떴고, 클릭→draft 문제집(1케이스)→EvalView 검토까지 이어졌다. 케이스 기준은
폴백이 아니라 **LLM이 합성한 구체 기준**("세종대왕 창제·1446 반포·훈민정음 포함하고 한 줄로 간결한가").
피드백→측정가능 평가 케이스라는 설계 목표([[numeric-verification-unlocks-autonomy]])가 실데이터로 실증됐다.

## 배운 것 (인프라 함정)
- **`uvicorn --reload`가 파일 저장마다 lifespan(=alembic upgrade)을 재실행한다.** 마이그레이션 파일을
  만든 직후 reload가 그걸 자동 적용·head 기록 → 그 뒤 같은 파일에 컬럼을 **추가해도 alembic은 head가
  이미 그 리비전이라 재실행 안 함**. 결과: DB가 반쪽 적용(harvested_case_pk만, source_agent_pk 없음)으로
  얼어붙고 API가 UndefinedColumn으로 부팅 실패. 교훈: **마이그레이션은 한 번에 완성해 저장**하거나, 편집
  후엔 수동 DDL/새 리비전으로 맞춘다(--reload 켠 채 마이그레이션 파일을 점진 편집 금지). [[hand-authored-migration-ids-collide-silently]]의 친척: alembic은 조용히 어긋난다.
- **진행 마커 단일출처에 새 경로가 등록을 빠뜨리면 폴링이 조기 종료.** `_is_generating`이 "AI 출제 중…"/
  "생성 중"만 알고 새 "피드백 수확 중…"을 몰라, 배경 작업 중인데 generating=False→테스트가 case_count=0을
  조기 판독. 단일출처는 새 종류를 추가할 때 **그 출처도 함께 갱신**해야 진짜 단일출처다.
- **우아한 저하 vs 하드 게이트는 "입력의 출처"로 갈린다.** suggest는 질문을 *발명*해서 실모델 없으면
  쓰레기→하드 게이트(mock이면 400). 수확은 질문이 *실제 사용자 메시지*라 LLM은 기준을 다듬을 뿐→llm_cfg
  =None이면 폴백 템플릿으로 진행. 같은 "도우미 LLM 의존"이라도 정답 요건이 달라 게이트가 다르다.

## codex가 잡은 것 (통합 24건이 못 본 여집합)
통합 테스트는 소유권·격리·idempotent·스탬프를 덮었지만, codex가 **다른 입구로 새는 콘텐츠**를 잡았다:
- **F1(High)**: 수확·수확수 입구는 게이트했지만 **eval 문제집 읽기는 본래 전원 공개(178 D1)**. 수확 케이스
  input=사용자 세션 질문이라, 남이 `GET /eval/datasets/{id}/cases`로 읽을 수 있었다. 한 입구(수확)만 잠그고
  **같은 자원의 다른 입구(공개 읽기)**를 안 본 전형적 누출([[installed-guard-isnt-covering-guard]]). →수확
  문제집(source_agent_pk≠NULL)은 세션 스코프 상속해 소유자/admin만. **입구를 셀 때 "이 콘텐츠가 흘러드는
  기존 공개 표면"까지 세라.**
- **F2(High)**: find-or-create가 소유권 게이트는 통과해도 **동시 첫-수확 경합**엔 무방비(2문제집·이중수확).
  기존 코드의 `pg_advisory_xact_lock`(eval 실행 가드) 패턴을 그대로 빌려 직렬화(마이그레이션 없이).
- **F4(Med)**: `assert_may_manage(None, superuser)`가 통과(특권 단락) → admin이 미존재 에이전트에 500.
  존재-404를 게이트 앞에 세우는 규율([[gate-on-intent-value-not-mutable-baseline]] 계열)을 새 입구가 빠뜨림.
- **F5**: 문제집 소유를 수확자로 스탬프 → admin이 남의 에이전트 수확 시 소유자가 관리 불가. 소유는 **자원의
  주인(에이전트 소유자)**을 따라야지 행위자를 따르면 안 된다.

## 다음에 적용
- 소유권 스펙에서 **입구 열거에 "이 데이터가 흘러드는 기존 공개 표면"을 포함**(F1). 새 콘텐츠를 공개 저장소
  (eval·검색 등)에 넣으면 그 저장소의 읽기 정책을 상속하는지 확인.
- **--reload 켠 채 마이그레이션 파일 점진 편집 금지** — 한 번에 완성하거나 편집 후 DB 상태를 측정·수동 정합.
- 진행 마커·게이트 같은 단일출처는 새 경로 추가 시 **그 출처 등록을 체크리스트로**.
- 배경 LLM 작업은 동시성뿐 아니라 **작업 크기 상한**도(F3, 무제한 항목당 콜=비용 폭주).
