# UI 전수 감사 (스펙 165·166·168·169)

자가검증이 관대한 건 구조 문제(같은 저자 사각 + 합격선 없음 → 재량 → 스킵). 처방 = **수치 임계 +
적대적 타자 + 합격선 아티팩트**. 이 스킬은 그 감사들을 **한 명령으로 재실행**해 "지속적 발견"을 상시화한다.

## 언제

UI/카피 변경 후 회귀 게이트, 주기적 점검, "어디가 깨졌나" 진단. 수동·CI·자율 루프 어디든.

## 실행 (기계 감사 3종)

dev 서버가 떠 있어야 한다(프리플라이트가 확인·down이면 중단 — 빈 화면을 통과로 오판 방지).

```bash
PLAYWRIGHT_DIR="$PWD/tests/e2e/node_modules/playwright" \
ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD=adminpass123 \
node tests/browser/audit-all.mjs
```

- **screens**(축2, `ui-audit.mjs`): 14화면 × 3뷰포트(360/768/1280) 가로 오버플로 수치 측정.
- **overlays**(축2 확장, `ui-audit-overlays.mjs`): 10 표면(모달·드로어·탭 — 능력 부여 탭·컬렉션
  편집·문서 드로어 포함) × 2뷰포트. **새 화면/탭/모달을 만들면 이 목록에 추가해야 감사가 따라온다**
  (커버리지 밖 초록은 공허 — 2026-07-07 감사에서 신설 표면 3개 누락 발견).
- **scenario**(축1, `scenario-audit.mjs`): 여정(생성→대화·지식 붙이기) 단계별 기대결과 대조. `scenarios.md`가 합격선.
- 종합 종료코드 = 하나라도 FAIL이면 1. 상세: `out-*/scorecard.json` + 스크린샷 `out-*/{viewport}/*.png`.

개별 실행도 가능(각 harness에 out-dir 인자). 서버 기동은 [[restart-dev-servers-for-tailscale]] 참고.

## 문구·평이함 (축3 — 별도)

기계화 불가(판단형). deep-reasoner에게 **"IT 모르는 일반인" 연기**로 위임, `tests/copy-rubric.md`를
합격선으로 사용자 노출 문자열 전수 채점. 막힘·오탈자 우선, 도메인어는 없애지 말고 설명 추가.

## 결과 트리아지 (핵심 규율)

- **도구가 좁히고 육안이 확정**: FAIL/후보를 스크린샷으로 육안 페어(정량이 flex 압착·잘림 못 잡음, 회고 133).
- **과잉 억제 금지**: 오탐 줄이려 필터를 세게 걸어 진짜 버그를 삼키면 새로운 관대함(회고 143). 증명된
  안전 패턴(off-screen·antd 탭)만 좁게 제외.
- **소프트 flag는 코드까지 추적**해 참/거짓 확정(손으로 안 흔든다, 회고 144·146).
- **clean pass도 정직한 산출물** — 없으면 없다고, 근거(스코어카드·스크린샷)와 함께.

## 테스트 인프라 함정

- antd 아이콘 버튼 접근성 이름 = `"edit 편집"` → `exact:true` 매칭 깨짐, 정규식 부분일치 써라([[142-antd-button-icon-aria-label]]).
- 모바일(<992px) DataTable = 카드(div) 렌더 → `table tbody tr` 0건, 뷰포트별 셀렉터 분기.
