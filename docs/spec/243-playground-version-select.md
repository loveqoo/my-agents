# 스펙 243 — 플레이그라운드 버전 선택 (242 UI)

## 배경
사용자 방향의 마지막 조각: "플레이그라운드에서 두(여러) 버전을 선택할 수 있게 — 세션 선택 전에 버전 선택."
242가 백엔드(ChatRequest.version·trace 기록·권한)를 깔았으므로 UI만 얹는다.

## 변경
- **플그 헤더에 버전 선택**(로컬 ui 에이전트 & 버전 존재 시): 기본="활성 vN", 초안·보관 선택 가능.
  버전을 바꾸면 **새 대화로 리셋**(오버라이드 "적용(새 대화)"와 동일 결 — 한 세션에 버전 혼재 방지.
  서버는 ask/form 재개 승계로 안전하지만 UI에서도 섞지 않는 게 명료).
- 미리보기 상태 표시: 활성이 아닌 버전 선택 시 "미리보기 vN" 배지(외부 서빙과 다름을 명시).
- streamChat에 version 전달(선택 시에만 — 미선택=활성, 무회귀).
- **인스펙터에 버전 표시**: trace.agentVersion(+versionPinned→"미리보기" 태그) — 세션에 섞인 과거
  턴도 어느 버전이었는지 식별(242 trace 기록의 소비처).
- 버전 미선택 유저(관리 권한 없음)는 서버 403 — UI는 관리 가능(can_manage) 에이전트에만 선택자 노출.

## 검증
- 브라우저 e2e: 초안 버전 선택→미리보기 배지→채팅→인스펙터에 "vN·미리보기", 버전 변경 시 새 대화,
  활성 복귀 시 배지 소멸. tsc 0. verify_242 무회귀.

## 완료 조건
- 플그에서 활성/초안을 골라 대화·비교할 수 있고, 어느 버전과 대화 중인지 항상 보인다. 외부(A2A)는
  여전히 활성만.

  활성 복귀=배지 소멸+새 대화. tsc 0. verify_242 무회귀(백엔드 무변경).
