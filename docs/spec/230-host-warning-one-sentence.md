# 스펙 230 — 허용 호스트 경고 배너를 한 문장으로 (나머지는 접이식으로)

## 배경 (사용자 스샷 지적 2026-07-08)

스펙 229로 SSRF 정의는 접었으나, 경고 Alert 자체가 아직 3문장(통과 사실·mock 예시·와일드카드 불가)이라
배너가 크다. "한 문장 정도만 노출하고 나머지는 숨기는 방식이 좋을 것 같아."

## 변경 (admin/src/admin/views/AllowedHostsView.tsx)

- 경고 Alert description을 **핵심 한 문장**으로: "여기 등록한 host는 사설/루프백/메타데이터 대역이라도
  서버의 바깥(outbound) 요청이 통과합니다 — 신뢰하는 대상만 추가하세요."
- 나머지 상세(통과 경로 A2A·MCP·Agent Card, 개발 mock 예시, 와일드카드·CIDR·포트·스킴 불가=정확 host)는
  "SSRF가 무엇인가요?" **Collapse 안으로 합침** — 정의에 이어 자연스럽게 규칙까지. (정확 host 규칙은
  호스트 입력 필드 extra 힌트에도 이미 상시 노출돼 이중 안전.)

## 검증
- 브라우저: 배너 description 마침표 1개·"신뢰하는 대상만 추가"만·상세(와일드카드/통과경로) 배너엔 없음,
  접힘 기본, 펼치면 정의+A2A·MCP·Agent Card+정확 host 모두. tsc 0.

## 비고
- 교훈: 상시 노출은 **행동을 좌우하는 핵심 한 줄**로 좁히고, 배경·부가 규칙은 접이식으로 밀어낸다. 정보를
  지우는 게 아니라 노출 계층을 나눈다([[explain-plainly-not-one-sided]]). 스펙 228→229→230 3단 축약.
