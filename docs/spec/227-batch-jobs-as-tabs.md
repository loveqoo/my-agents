# 스펙 227 — 배치 4개 잡을 탭으로 구성

## 배경 (사용자 제안 2026-07-08)

"배치를 탭으로 구성하는 거 어때요?" 배치 화면은 네 잡 카드(세션 정리·메모리 통합·A2A 정크·테스트 유저)를
세로 나열해 스크롤이 길었다. 각 잡은 **설정 폼·동작이 서로 다른 별개 도구**라 탭 규칙(스펙 212: 데이터/도구
전환=Tabs)에 부합.

## 변경 (admin/src/admin/views/BatchView.tsx)

- 상단에 `Tabs`(언더라인 스위처) 추가: [세션 정리 · 메모리 통합 · A2A 정크 · 테스트 유저]. 라벨은 짧게,
  각 패널 내부 h4에 풀네임+코드 유지.
- 네 `<Panel>`을 `{job === '...' && (...)}`로 조건 렌더 — 활성 잡만 표시. `job` 상태(useState) 추가.
- **실행 이력(공용)은 탭 아래 공통**으로 유지 — 어느 잡을 트리거해도 아래에서 바로 확인. 탭 전환과 무관.
- 입력 상태(days·minTurns·cron·threshold·memCron·userPattern)는 컴포넌트 상태라 **탭 전환에도 보존**.

## 검증
- 브라우저: role=tab 4개, 기본 세션 패널만·타 잡 패널 숨김, A2A 탭 전환 시 a2a 패널만·세션 숨김, 모든 탭에서
  실행 이력 노출. tsc 0.
