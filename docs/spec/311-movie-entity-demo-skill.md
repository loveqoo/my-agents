# 311 — 영화 엔티티 데모 로더 (임베딩 모델 선택형 스킬)

## 배경 (사용자 결정, 2026-07-12)
엔티티 RAG(스펙 149)는 **첫 구동 예제가 없다** — 기능은 있으나 처음 켜면 엔티티 컬렉션이 0개라
"이게 뭔지" 안 보인다. seed에 mock-embed로 박으면 **의미 없는 검색**(해시 벡터)이라 데모 가치가 약하고,
seed도 무거워진다(스펙 303 최소주의 역행).

대신 **임베딩 모델을 골라 영화 엔티티 데모를 심어주는 재사용 로더**를 만든다(사용자 방향). 모델 선택이
핵심 — 상황마다 다 산다:
- **개발/CI**: `mock-embed` → 1024차원·결정적 → **스펙 310 평가 판정의 실측 픽스처**
- **실 배포**: `snowflake-arctic` 등 실모델 → **진짜 의미 검색** 데모("우주 고립"→인터스텔라 실제 동작)
- **seed는 깨끗**(영화 안 박음) + 어느 환경서든 재사용(크래프트 자산). 스펙 310의 픽스처 공급원.

영화는 시맨틱 검색 데모의 정석(줄거리가 의미로 검색됨·행마다 구조화 id) — Qdrant/Kaggle 데모 관행.

## 설계

### 1. 영화 엔티티 데이터셋 (`packages/api/data/entity_samples/movies.jsonl`)
스펙 149 JSONL 계약 `{"metadata": {…}, "data": …}`. ~10편, 장르 섞음(검색 변별). metadata는 **숫자 id
여럿**(사용자 실데이터 `sql_filter_key_id` 형태 미러 — 스펙 310 숫자/조합 판정 실증):
```
{"metadata": {"movie_id": 101, "director_id": 1, "genre_id": 1},
 "data": "인터스텔라 — 지구의 종말이 다가오자 한 우주비행사가 웜홀 너머로 인류의 새 터전을 찾는다. 시간·중력·부성애의 SF."}
```
- `genre_id` 공유(1=SF,2=드라마,3=코미디,4=액션,5=애니,6=로맨스…)·`director_id` 일부 공유(예 위플래쉬·
  라라랜드 동일 감독) → **부분/조합 키 매칭 데모**(genre_id로 여러 편, movie_id로 유일).

### 2. 인제스트 스크립트 (`packages/api/scripts/ingest_movie_entities.py`, `ingest_rag_samples.py` 미러)
- 인자: `--model <임베딩모델명>`(기본=기본 임베딩 모델)·`--collection <이름>`(기본 `movies-demo`, 네이밍
  규칙 스펙148 대시).
- 동작: (게이트) 임베딩 모델 없으면 스킵 → 없으면 `kind='entity'` 컬렉션을 **선택 모델에 바인딩** 생성
  → `movies.jsonl`을 실 인제스트 엔드포인트로 적재(parse→embed→pgvector 전 경로) → 검색 1회 확인.
- **멱등**: 이미 채워졌으면(doc/chunk>0) 스킵. 라이브 서버(mock `/_remote/v1/embeddings` 또는 실모델
  원격)를 임베딩 대상으로 사용(ingest_rag_samples 전제 동일).

### 3. 스킬 (`.claude/skills/movie-demo/SKILL.md`, agent-flow 포맷)
frontmatter `name`·`description`("영화 엔티티 데모 심기", "엔티티 RAG 데모/평가 픽스처" 트리거) + 지침:
1. 등록 임베딩 모델 열거 → **하나 선택**(기본=기본 임베딩 모델, 사용자 확인).
2. 스크립트 실행(선택 모델).
3. 검색 1회로 동작 확인 + 결과의 metadata 노출 확인.
4. (안내) 이 컬렉션으로 스펙 310 `rag_meta_contains` 평가를 걸 수 있음.

## 정직한 한계 / 주의
- **mock-embed는 비의미(결정적)**: 개발서 mock 고르면 검색 순위가 일관되나 의미 아님 → 데모 품질은
  실모델서. 컬렉션 임베딩 모델은 **생성 후 불변**(스펙149)이라 로드 시 **맞는 모델을 골라야**(바꾸려면
  새 컬렉션).
- 라이브 서버 전제(임베딩 엔드포인트 도달) — ingest_rag_samples와 동일 제약.
- seed 무변경(영화 안 박음) — 로더는 온디맨드.

## 검증
- **실 인프라(dev, mock-embed)**: 스크립트 실행 → `kind='entity'` 컬렉션 생성·movies.jsonl 전건 인제스트
  (chunk 수=행 수·각 chunk에 metadata 저장)·검색 1회가 엔티티 결과+metadata 반환. **멱등 재실행** 스킵.
- **자가 무결**: 검색 결과 hit의 meta에 movie_id 등 id들이 실려 나오는지 단언(스펙310 판정 전제).
- **스킬 왕복**: 스킬 지침대로 모델 열거→선택→적재→검색이 도는지 실행(메인이 직접).
- (실모델 의미 품질은 사용자 배포 환경 — dev 범위 밖, 정직 기록.)

## 관계
- 스펙 310(엔티티 평가 판정)의 **픽스처 공급원**. 순서: 311(로더·엔티티 컬렉션 확보) → 310(그 위 판정).
- 번호>310이나 **먼저 실행**(사용자 결정) — 스펙 번호는 식별자, 실행 순서 아님.
