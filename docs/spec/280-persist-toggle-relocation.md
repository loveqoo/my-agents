# 280 — "대화 저장" 토글을 "저장 방식" 아래로 + 관계 설명 부착

> 사용자 질문("영속(기본)과 대화 저장 토글의 차이는?")이 신호 — 두 설정은 포함 관계(비영속 ⊃ 대화
> 저장 끔)인데 step ①과 step ③에 떨어져 있어 관계가 안 보였다. 지시: "대화 저장을 저장 방식 아래로
> 붙입시다. 약간의 간결한 설명을 붙입시다."

## 변경
- step ③ 세부의 '저장·영속' 구획(대화 저장 토글 단독)을 **step ① 저장 방식 Field 바로 아래로 이동**
  (구획 자체 소멸 — 세부에는 플레이그라운드 구획만 남음).
- 간결한 관계 설명 부착: 영속일 때 "대화 내용(메시지)만 저장할지 — 꺼도 세션·기억·통계는 유지",
  비영속일 때 기존 실효값 표시(토글 꺼짐+disabled) 유지.
- 저장 데이터(persistHistory)·백엔드 무변경. 라벨은 "대화 저장" 유지(위치가 관계를 설명).

## 완료 조건
1. step ①: 저장 방식 바로 아래 대화 저장 토글(순서 e2e), step ③에 '대화 저장'·'저장·영속' 부재.
2. 관계 설명 문구 노출(영속: "…세션·기억·통계는 유지").
3. 기능 무회귀: 토글 off 저장 왕복 persistHistory=false, 비영속 시 disabled(기존 279 ② 동작 유지).
4. tsc 0 + 279 e2e 무회귀.
