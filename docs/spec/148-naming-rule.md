# 148 — 네이밍 규칙 (사용자 지정)

## 규칙
`_` 금지(대신 `-`) · 공백 금지 · 영어 대문자 금지. 허용: 한글·영소문자·숫자·대시(`-`)·마침표.
정규식: `^[가-힣a-z0-9.\-]+$` (선행/후행 대시 및 연속 대시는 v1 허용 — 과규제 회피).

## 적용 대상 (생성·이름 변경 시 400, 서버가 진실원 — 프론트는 힌트만)
에이전트(생성/수정/복제 시 이름)·RAG 컬렉션·페르소나·권한·MCP 서버.
**제외**: 원격 유래 이름(external 에이전트 카드명·code 등록명·MCP 도구 탐색 결과) — 우리가
짓는 이름이 아님.

## 기존 데이터
일괄 개명은 **이름 참조를 깬다**(에이전트 설정이 mcp/rag를 이름으로 참조 — move-breaks-references).
→ 신규·변경만 강제(grandfather). 위반 현황(2026-07-03): 에이전트 5(Doc Translator·Plan-Execute
Demo·Personal Secretary·Research Assistant·옵시디언 매니저), rag 2(Obsidian·docs_kb → docs_kb는
_만 위반), 페르소나 4. UI에서 점진 개명 권장(개명 시 참조 갱신은 사용자 책임 — 후속: 참조 자동
갱신 스펙 검토). ※공백 금지는 한글에도 적용("옵시디언 매니저"→"옵시디언-매니저").

## 구현
- 공용 검증기 `validate_resource_name(name)` (api/naming.py) — 5개 생성/수정 라우트에서 호출.
- 프론트: 각 이름 Input에 힌트+즉시 검사(제출 전 안내).
- 검증: 단위(허용/거부 표본)·라우트별 400·원격 유래 비적용 확인. e2e 간단(생성 폼 거부 메시지).
