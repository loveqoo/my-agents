# 스펙 225 — 유저 메뉴 권한 부여 어휘 정리 (능력→권한 등)

## 배경 (사용자 지적 2026-07-08)

유저 메뉴 권한 부여 UI의 표현이 어색:
1. '능력' → **'권한'** (permission이 더 자연스러움 — 권한 재설계 방향과도 부합).
2. '역할에게' → (1차 '역할 기준' → 사용자 정정) **'권한 기준'**.
3. '특정 유저에게' → **'유저 기준'**.

## 변경 (admin/src/admin/views/UsersView.tsx — 표시 문자열만)

- **'능력' → '권한' 전량 치환**(탭 '권한 부여', 도입문 "권한이란…", '권한 종류', '권한' 컬럼, 부여/회수
  토스트, '부여된 권한 없음' 등). 표시용 '능력'은 UsersView에만 있었고 타 화면과 안 겹침(확인). 코드
  식별자(capability·policy)는 영어라 불변 — UI 라벨만 변경.
- 부여 대상 탭: '권한 기준'(역할 축) · '유저 기준'(유저 축).

## 검증
- 브라우저: 탭 [유저 목록·권한 부여] + 하위 [권한 기준·유저 기준], 본문 '능력' 0건, '권한 종류'·'권한이란'
  표기. tsc 0.

## 비고
- 백엔드 `capability:{kind}` 개념·API는 불변(UI 어휘와 분리).
- 결과 라벨쌍 "권한 기준/유저 기준"은 사용자 확정(1차 '역할 기준'에서 정정).
