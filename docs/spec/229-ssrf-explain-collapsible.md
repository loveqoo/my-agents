# 스펙 229 — 허용 호스트: SSRF 상세 설명을 접이식으로 (매일 볼 필요 없음)

## 배경 (사용자 지적 2026-07-08)

스펙 228로 SSRF 설명을 추가했으나, 사용자: "SSRF 설명이 자세한 것은 알겠는데, 매일 보고 싶지는 않아."
→ 상세 정의가 상시 화면을 차지. 필요할 때만 펼쳐 보게.

## 변경 (admin/src/admin/views/AllowedHostsView.tsx)

- 경고 Alert(보안 주의)는 그대로 상시 노출(중요한 행동 주의) — description은 다시 간결한 한 단락.
- SSRF **정의**(228서 배너에 넣은 상세)를 antd `Collapse`(ghost, size small, **기본 접힘**)로 분리 —
  헤더 "SSRF가 무엇인가요?"만 한 줄로 보이고, 클릭 시 정의 펼침.

## 검증
- 브라우저: 접힘 기본 상태에 토글 헤더만·상세 정의(서버 측 요청 위조) 숨김·경고는 노출, 헤더 클릭 시 정의
  펼침. tsc 0.

## 비고
- 교훈: 교육용 상세는 **상시 노출 vs 필요 시 노출**을 가른다 — 경고(행동 주의)는 상시, 정의(배경 학습)는
  접이식. "충분히 자세히"와 "매일 보이게"는 다르다. antd Collapse가 규칙상 접이식 담당(admin/CLAUDE.md).
