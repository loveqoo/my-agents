# 135 — 드로어/인스펙터 Escape 닫기 통일 (모바일 점검 후속)

## 배경 / 왜
드로어 모바일 점검(fast-worker, 6대상): 가로 넘침 0건 — 폭 클램프는 건전. 진짜 갭 = **닫기 수단
불일치**: antd Drawer(문서 관리·오버라이드)는 Escape 닫힘, **커스텀 Drawer**(shared.tsx — 세션·
에이전트·블록 상세)와 **인스펙터**(전체화면 오버레이)는 Escape 리스너가 없어 안 닫힘. 모바일에선
전 대상이 패널 100% 폭이라 마스크 탭도 불가(구조상 — 수용) → X 버튼 단일 의존.

## 설계
1. shared.tsx `Drawer`: open일 때 document keydown Escape → onClose (antd와 거동 통일).
2. `Inspector`: 열려 있을 때 Escape → 닫기(같은 패턴).
3. 마스크 탭 불가(모바일 100% 폭)는 의도된 구조로 수용 — X + Escape 두 수단이면 충분(OUT 명시).

## 검증
- 브라우저: 세션 상세(커스텀)·인스펙터에서 Escape 닫힘(모바일+데스크톱), antd 드로어 무회귀(여전히
  닫힘), 드로어 안 Input 포커스 중 Escape는 antd 관례대로 닫힘 허용. tsc.

## 비목표 (OUT)
- 마스크 탭 닫기 복원(모바일 100% 폭 구조 유지)·스와이프 제스처.
