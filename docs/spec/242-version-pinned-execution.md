# 스펙 242 — 버전 지정 실행(내부 서빙) + 버전별 평가 (AgentOps)

## 배경 (사용자 방향 2026-07-08)

"서빙 중인 것만 평가 가능한 게 허들 — 내부는 버전별로 서빙(테스트 가능)하고, 외부는 최종 하나만.
플레이그라운드에서 버전 선택, 버전별 테스트." 241의 정직 경계("배포 전 게이트 불가")를 구조로 푼다.

**핵심 관찰**: AgentVersion이 버전마다 완전한 config 스냅샷을 이미 보유 — "버전별 서빙"은 배포 N개가
아니라 **컨텍스트 로드 시 config 소스 전환**이다.

## 변경

### 백엔드 — 버전 지정 실행
- `ChatRequest.version: str | None` — 지정 시 `_load_context`가 그 AgentVersion의 config로 ctx 구성
  (persona는 이름→본문 재해석). 미존재 버전 404, 원격(code/external) 에이전트는 400(로컬 실행 전용).
- **외부 경계 공짜 유지**: A2A·공개 서빙 경로는 version 파라미터가 없음 → 활성 버전만 나감.
- **실행 버전 기록**: 모든 턴 trace에 `agentVersion`(지정 버전 또는 활성 버전) — 인스펙터·세션에서
  "이 턴이 어느 버전이었나" 추적(240의 평가 귀속과 대칭).
- **HIL 경계(정직)**: 버전 미리보기 턴에서 승인형 도구가 멈추면 명시 에러(235 비영속 게이트 패턴) —
  승인 재개는 서빙 config로 돌아 버전이 어긋난다(drift). 재개 관통은 필요 실증 시 후속.

### 평가 — 버전별 테스트
- `RunStartIn.agent_version` — 지정 시 그 버전 config로 평가(러너에 version 관통). EvalRun.agent_version
  =**실행한 버전**(240 의미 확장: 지정 시 지정 버전, 아니면 활성), env도 그 버전 config 기준.
- **"배포 전 게이트" 성립**: 초안을 활성화 전에 평가 → 통과 확인 → 활성화(→ 241 자동 회귀가 재확인).
- EvalView 실행 폼: 에이전트 선택 시 버전 Select(기본=활성, 초안·아카이브 선택 가능).

### 플레이그라운드 버전 선택은 스펙 243(다음)
세션 시작 전 버전 선택 UI + 트레이스 버전 표시 — 이 스펙의 백엔드 위에 UI만.

## 검증
- 실측: 초안 config(페르소나 차이)로 버전 지정 채팅 → 응답/trace가 초안 기준. 미존재 버전 404.
  버전 지정 평가 → EvalRun.agent_version=지정 버전·env=그 버전 config 기준. 활성 실행 trace에도
  agentVersion 기록. 버전 미리보기+승인형 도구 → 명시 에러+DB 무오염.
- verify_240/241 무회귀. codex 적대(외부 경계 우회·오버라이드와의 결합·재개 drift).

## 완료 조건

  귀속된다. 초안 평가로 배포 전 확인이 가능하다.
