## 변경

1. **[버그] 구성 카운트를 276 체계로**: 개요 '구성' 행의 `도구 N`이 `mcps.length`(서버 수) —
   276 이후 진실원은 `agent.tools`(도구 단위). `tools.length ? '도구 N' : mcps.length ?
   '도구 서버 N(전체)'`(빈 tools=서버 전체 폴백을 정직 표기). 노드형은 도구가 노드 소유라
   `노드 N` 요약으로 대체.
2. **[버그] 종류 라벨 단일 출처**: 헤더의 로컬 typeLabel 사본이 `pipeline` 내부 키를 그대로
   노출(스펙 108 위반 — '노드형'이어야). AgentForm의 `typeLabel(impl)`(283 단일 출처)로 교체,
   로컬 사본 삭제.
3. **헤더 배지 슬림화(284 계승)**: 배지 = **신호등 점+라벨(상태) · 종류 · 예외 태그만**
   (설정 실패 red, 비영속 orange). 제거: `public/private` 태그(공개·연동 탭이 소유, 284에서
   목록 태그 소멸과 동일 근거) · `초안 vN` gold 태그(개요 버전 행·버전 탭과 3중 중복) ·
   `A2A` green 태그(개요 공개·연동 행이 소유) · `서빙 vN`/`미서빙 · 초안만` 태그(신호등이 대체,
   버전은 개요 행에 있음). 신호등 색·의미는 284 LIGHT와 동일(파랑/노랑/빨강).
4. **노드형 구성 표기**: 구성 탭에 '노드' 행 신설 — `이름(모델)` 화살표 연결 요약. 직접형
   구성 탭의 'MCP' 행(서버 태그) → '도구' 행: `tools` 있으면 `서버 · 도구` 태그, 없으면
   기존 서버 태그(전체 폴백 정직 표기).
5. **어휘·문구 정리**: 개요 '구성' 행 `메모리 N`→`기억 N` · 구성 탭 '벡터 테이블'→'문서' ·
   하단 연결 없음 문구 `메모리`→`기억`, `도구(MCP)`→`도구` · 개요 '운영' 행 `지표 없음`→
   `피드백 아직 없음`(운영 탭 점프는 유지 — 수확 도구가 있어 죽은 행 아님).
