# 스펙 217 — 식별 이름 규칙: 영소문자·숫자·대시만 (한글·마침표 제거)

## 배경 (사용자 지시 2026-07-07)

RAG 컬렉션(및 전 리소스)의 식별 이름에 한글이 허용되던 것을 사용자가 지적: "나는 영어 소문자, 대시,
숫자만 원했어." 기존 규칙(스펙 148) `^[가-힣a-z0-9.\-]+$`은 한글·마침표를 허용 → **영소문자·숫자·대시만**으로 좁힘.

## 조사 (파급 — 안전 확인)

- 규칙은 **전 리소스 공용**(NAME_RE 하나 — 페르소나·MCP·에이전트·컬렉션이 `_assert_valid_name`으로 소비).
- 기존 DB 실측: 컬렉션·페르소나·MCP·에이전트에 **한글/마침표 이름 0건** → 좁혀도 안 깨짐(V6가 회귀 검증).
- 메모리 타입은 한글 키를 갖지만 `_assert_valid_name`을 **안 탐**(시드 카탈로그, 읽기 전용) → 무관.

## 변경

### 1. 규칙 (진실원 백엔드 + 프론트 미러)
- `packages/api/src/api/naming.py`: `NAME_RE = ^[a-z0-9\-]+$`, 힌트/독스트링 갱신.
- `admin/src/admin/naming.ts`: `NAME_RULE = /^[a-z0-9\-]+$/`, `NAME_HINT` 갱신.

### 2. slugify (원격 유래 자동 변환) — 생산자도 규칙 준수
- 불허 문자 제거를 `[^a-z0-9\-]`로(한글·마침표 탈락). 양끝 `strip("-")`.
- **fallback 기본값 `"이름-미상"`(한글) → `"unnamed"`(영문)** — 폴백도 규칙을 지켜야 함(한글 폴백은 새 규칙 위반).

### 3. 숨은 생산자 수정 — 에이전트 복제 접미
- `agents.py` clone: `name=f"{src.name}-복사본"` → **`-copy`**(한글 이름 생성 버그). 설명은 "(복사본)" 유지(자유 표기).

- 브라우저: RAG 컬렉션 생성 모달 힌트 "영소문자·숫자·대시(-)만" 표시. tsc 0.
