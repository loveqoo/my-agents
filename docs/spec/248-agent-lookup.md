# 스펙 248 — 플레이그라운드 에이전트 조회·시작 환경 (루프의 첫 단추)

## 배경 (247 후속 — 사용자 지정)

집중 모델의 루프("에이전트를 찾고 → 환경을 구성하고 → 빠르게 대화")에서 첫 단추가 병목:
에이전트 콤보에 **검색 없음**(많아지면 스크롤 탐색), **최근 사용 정렬 없음**, 고른 직후 **조건 요약
없음**(어떤 버전·오버라이드로 시작하는지 안 보임).

## 변경

1. **콤보 검색** — 드롭다운 상단 검색 입력(이름·모델·페르소나 부분일치, 열릴 때 자동 포커스).
2. **최근 사용 정렬** — 전환할 때마다 localStorage(`pg_recent_agents`, 최대 8)에 기록, 드롭다운은
   최근 사용 순 → 나머지 이름순. 최근 항목엔 "최근" 표식.
3. **시작 조건 요약** — 빈 대화(시작) 상태에 한 줄: "활성 v3 · 오버라이드 없음 — [대화 설정]에서 변경".
   기본과 다르면 신호 배지가 이미 헤더에 있으므로, 이 줄은 **시작 화면 한정**(대화 시작 후엔 소멸 —
   상시 요소 늘리지 않음, 247 문법 유지).
4. **선택 후 입력 자동 포커스** — 고르면 바로 칠 수 있게.

## 검증
- e2e: 검색 필터 동작(부분일치·무일치 빈 상태)·전환 후 재열기 시 최근 순·시작 화면 조건 요약(대화
  시작하면 사라짐)·선택 후 입력 포커스. 모바일 360px 오버플로 0. 기존 247 e2e 무회귀.

## 후속 수정 2 (사용자 플로우 명세 — 시작 캐스케이드 "선택지 있을 때만 고르게")
사용자 명세: 에이전트(최근 위·1개면 자동) → 버전(1개면 자동) → A2A(비공개면 직접 자동) → 세션(비면
자동 새 세션·있으면 최근 위) → 대화 포커싱. 기존 동작 대조 결과 대부분 충족(세션 서버 최근순·자동
새 세션·직접 기본·전환 포커스), 차분 2건 구현:
- **초기 에이전트 = 최근 사용 자동 선택**(localStorage, 재방문 이어서 — 없으면 첫 항목=1개면 자동).
- **버전 선택은 선택지(비활성 버전) 실재 시만 노출**(활성 1개뿐이면 자동 선택과 동치 — UI 미노출).
- e2e 4/4(재진입 자동 선택·즉시 포커스·버전 1개 미노출·선택지 생기면 노출) + 247/248 무회귀.

## 후속 수정 3 (사용자 교정 — "스마트 자동 선택은 노출돼야 한다. 인지의 관점")
- 원리 교정: **컨트롤을 가리는 것(집중)과 상태를 가리는 것은 다르다.** 자동으로 골라졌을수록 무엇이
  선택됐는지 보여야 한다(숨은 상태=인지 불확실성). "기본과 다를 때만 배지" 규칙을 상태에 적용한 게
  잘못 — 그 규칙은 *경고*용이지 *상태*용이 아니다.
- 구현: **상시 조건 표시줄** — 에이전트 콤보 옆 "활성 v1 · 직접 · 새 대화(또는 이어서: 미리보기)
  (· 오버라이드 ✓)". 조용한 3차 텍스트, 기본과 다른 값만 색 태그. **클릭=대화 설정**(상태 표시가 곧
  변경 입구). 시작 화면 한정 요약은 중복이라 제거(초안 중복 교훈 재적용).
- e2e: 표시줄 상시(대화 후 '이어서' 반영)·클릭→설정 열림·모바일 0. 247/248 무회귀.

## 후속 수정 18 (사용자 실기기 캡처 — 닫힘/열림 시 서랍 비침)

## 후속 수정 19 (사용자 — 닫기도 같은 손잡이로: 서랍 하단 U)
