# 스펙 248 — 플레이그라운드 에이전트 조회·시작 환경 (루프의 첫 단추)

## 배경 (247 후속 — 사용자 지정)

집중 모델의 루프("에이전트를 찾고 → 환경을 구성하고 → 빠르게 대화")에서 첫 단추가 병목:
에이전트 콤보에 **검색 없음**(많아지면 스크롤 탐색), **최근 사용 정렬 없음**, 고른 직후 **조건 요약
없음**(어떤 버전·오버라이드로 시작하는지 안 보임).

## 변경

1. **콤보 검색** — 드롭다운 상단 검색 입력(이름·모델·페르소나 부분일치, 열릴 때 자동 포커스).
2. **최근 사용 정렬** — 전환할 때마다 localStorage(`pg_recent_agents`, 최대 8)에 기록, 드롭다운은
   최근 사용 순 → 나머지 이름순. 최근 항목엔 "최근" 표식.
3. **시작 조건 요약** — 빈 대화(시작) 상태에 한 줄: "활성 v3 · 오버라이드 없음 — [대화 설정]에서 변경".
   기본과 다르면 신호 배지가 이미 헤더에 있으므로, 이 줄은 **시작 화면 한정**(대화 시작 후엔 소멸 —
   상시 요소 늘리지 않음, 247 문법 유지).
4. **선택 후 입력 자동 포커스** — 고르면 바로 칠 수 있게.

## 검증
- e2e: 검색 필터 동작(부분일치·무일치 빈 상태)·전환 후 재열기 시 최근 순·시작 화면 조건 요약(대화
  시작하면 사라짐)·선택 후 입력 포커스. 모바일 360px 오버플로 0. 기존 247 e2e 무회귀.

## 완료 조건
- 에이전트 N십 개여도 두 타 안에 찾고, 시작 조건이 보이는 채로 바로 첫 메시지를 칠 수 있다.
