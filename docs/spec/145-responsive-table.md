# 145 — 반응형 테이블 (에이전트 리스트 재보고 반영)

## 배경
144의 "가로 스크롤"은 오답 — 사용자: "다양한 가로 사이즈에서 테이블이 잘 보이도록(모바일
최적화) **반응형으로**". 진단: 공유 DataTable은 모바일(<768)엔 이미 카드 스택이 있으나,
그 이상 폭에선 `minWidth: max-content`(표가 내용만큼 넓어짐)+`nowrap`이라 중간 폭에서
컨테이너를 넘쳐 스크롤 발생.

## 설계 (공유 DataTable 자체 개선 — 전 화면 수혜)
1. 데스크톱 표를 **컨테이너 폭에 맞춤**: `minWidth: max-content` 제거, td 내용 줄바꿈 허용
   (overflowWrap), th는 nowrap 유지(헤더는 짧음). 열은 폭에 따라 자연 축소·내용은 여러 줄.
2. 가로 스크롤 래퍼·sticky 액션 열은 **안전망으로만 유지**(정상 케이스에선 발동 안 함).
3. 모바일 카드 스택(<768)은 그대로(이미 반응형의 최하단 단계).
4. hideBelow는 계속 미사용(144에서 제거) — "숨기지 않고 맞춘다"가 원칙.

## 검증
- e2e(fast-worker): 에이전트 리스트를 1400/1024/820/600/390px에서 — 600px 이상에선
  **가로 스크롤 0**(scrollWidth==clientWidth)+전체 컬럼 표시, 390px에선 카드 스택.
  세션·평가 등 다른 표 1~2곳도 회귀 확인(공유 컴포넌트 변경). 스샷 3장(사용자 확인용).
