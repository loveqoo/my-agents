# 스펙 226 — 배치 화면 폼 레이아웃 정돈 (힌트 아래 정렬·관련 필드 나란히)

## 배경 (사용자 지적 2026-07-08)

배치 메뉴 "스타일 또는 컴포넌트 배치를 잘 조절할 필요가 있어보여." 각 잡 카드의 입력 필드가 느슨:
좁은 InputNumber(160px) **오른쪽에 힌트 텍스트가 떠 있어**(`marginInlineStart` span) 입력이 고아처럼
보이고 시각 리듬이 들쭉날쭉.

## 변경 (admin/src/admin/views/BatchView.tsx — 레이아웃만)

- 모든 필드의 오른쪽 떠 있던 힌트 span → **`Form.Item extra`**(필드 아래 정렬, antd 관용 muted). 4개
  패널의 6개 힌트(보존일수·최소 턴 수·통합 임계치·cron×2·이메일 패턴) 일괄.
- 세션 정리의 관련 두 숫자 필드(보존일수·최소 턴 수)는 **나란히**(flex gap 24, wrap) — 두 삭제 기준이
  한 줄에. 세로 스택으로 길어지던 걸 상쇄.
- 각 폼 마지막 필드는 `marginBottom: 0`(버튼과의 간격은 기존 `marginTop: 16` 유지).

로직·입력 상태·버튼(설정 저장/Dry-run/지금 실행)·데이터 불변. 순수 표시 배치.

## 검증
- 브라우저(1280): 4개 패널 모두 힌트가 필드 아래 정렬, 세션 두 필드 나란히, a2a(폼 없음)·이력 테이블
  정상. tsc 0.

## 비고
- 교훈: 좁은 입력 + 오른쪽 힌트 span은 느슨해 보인다 — antd는 `Form.Item extra`(아래)로 힌트를 붙이는 게
  관용이자 정렬이 맞다. 관련 필드는 나란히 묶어 세로 길이를 줄인다.
