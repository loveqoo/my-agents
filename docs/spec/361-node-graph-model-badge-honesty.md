# 361 — 플레이그라운드 상단 모델 배지 정직성 (노드형은 노드별 모델)

## 왜 (실물 확증 — 사용자 신고)

노드형(agent-flow) 에이전트의 각 노드에 실제 모델을 할당했는데, 플레이그라운드 상단 **모델 배지가
mock-llm**으로 뜬다. "노드형은 (상위) LLM 모델을 특정할 수 없는데 이 부분 버그 같다"(사용자).

**근인**: 배지(`DebugChat.tsx modelBadge`)가 에이전트의 **상위 `model` 필드**를 그대로 표시한다. 그런데
노드형은 실행 모델이 **노드마다** 다르고, 상위 `model`은 실행에서 미참조(노드 모델 미지정 시 폴백만,
learning 152). 그래서 노드에 실모델을 넣어도 상위 기본값(mock-llm)이 배지에 떠 거짓 표기가 된다.

## 설계

`modelBadge`에 노드형(`impl === 'pipeline'`) 분기를 추가한다 — 상위 model 대신 **노드 모델**을 표기:
- 노드 모델이 모두 같으면 그 모델명(툴팁 "모든 노드가 이 모델").
- 다르면 `노드별 N개`(툴팁에 모델 목록).
- 노드 미해결(참조 미해결 등)·모델 미지정이면 상위 폴백값을 표기하되 "노드형 — 폴백" 안내(단일 모델
  단언 회피). `resolvedNodes`(스펙 316 파생)에서 노드 모델을 읽는다. code/external 분기와 동렬.

## 완료 조건

- **C1** 노드형 에이전트 배지가 노드 모델(들)을 표기 — 상위 mock-llm 단독 표기 안 함.
- **C2** 무회귀 — ui(단순)·code(원격 SDK)·external(외부 A2A) 배지 불변. tsc 0.
