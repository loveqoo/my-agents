# 스펙 214 — 에이전트 '태그 안내' 팝업 레이아웃 정돈

## 배경 (사용자 실사용 지적 2026-07-07, 스샷)

에이전트 목록의 '태그 안내' Popover가 태그와 설명을 한 flex(wrap)에 섞어 흘려, 설명이 태그 뒤에서
불규칙하게 줄바꿈돼 정렬이 깨지고 지저분했다("너무 지저분한 레이아웃").

## 변경 (admin/src/admin/views/AgentsView.tsx)

- 각 행의 `flex flexWrap`(태그+설명 혼류)을 **2열 CSS 그리드**(`gridTemplateColumns: '128px 1fr'`)로 교체.
  - 왼쪽 열: 태그 그룹(고정폭 내 wrap) → 설명 시작선이 모두 정렬됨.
  - 오른쪽 열: 설명(text-secondary, lineHeight 1.5) → 공통 좌측 정렬.
- 마지막 "상태·A2A 스위치" 노트는 **구분선(borderTop) 아래**로 분리(요약 성격 → 시각 분리).
- 의미·문구·태그 색은 불변(레이아웃만).

## 완료 기준
- tsc 0, 브라우저에서 Popover가 태그 열/설명 열 정렬 + 하단 노트 분리로 렌더(스샷 확인).
