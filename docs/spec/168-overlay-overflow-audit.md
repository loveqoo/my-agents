# 168 — 드로어·모달 오버플로 감사 (축2 확장)

## 배경
스펙 165(ui-audit)는 top-level 화면만 봤다(드로어/상세/모달은 OUT). 모달·드로어는 폭이 고정적이고
필드가 빽빽해 **모바일서 오버플로가 숨는 전형 위치**. 같은 MEASURE(rect.right>vw+pageScroll)를 오버레이에 적용.

## 대상 오버레이(열기 시퀀스)
- 에이전트 생성 모달: 에이전트 → "새 에이전트".
- 에이전트 상세 드로어: 에이전트 → 첫 행 클릭.
- 페르소나 편집: 빌딩 블록 → 페르소나 탭 → 첫 행.
- 컬렉션 생성 모달: RAG 컬렉션 → 생성 버튼.
- 프로바이더/모델 추가 모달: 프로바이더·모델 → 추가 버튼.
- 플레이그라운드 오버라이드·인스펙터 패널: Playground → 오버라이드 / 인스펙터 버튼.

## 하네스: tests/browser/ui-audit-overlays.mjs
- ui-audit.mjs의 MEASURE 재사용(같은 판정: rect.right>vw 초과·의도적 스크롤/탭 흡수 제외).
- 오버레이별로 열기 → 뷰포트(360 mobile·1280 desktop)에서 측정·스크린샷 → 닫기.
- **오버레이 내부 스크롤 컨테이너**(모달 body가 overflow:auto면 세로 스크롤 정상)는 가로만 본다.
- 생성 모달은 열기만(저장 안 함) — 엔티티 안 만듦(오염 0). 저장 흐름은 시나리오 감사(166) 담당.
- 출력: out-overlay/scorecard.json + png. FAIL(가로 오버플로) 있으면 exit 1.

## 검증
실행 → FAIL 적대 트리아지(진짜 가로 넘침 vs 오탐: 모달 뒤 배경 요소·닫힌 패널). 진짜만 수정(반응형
폭·wrap·max-width) 후 재실행 수렴. 육안 페어(회고 133).

## OUT
- 세로 잘림/스크롤. 저장 후 상태 오버레이. 중첩 드로어(드로어 안 드로어). 축1·3 재실행.
