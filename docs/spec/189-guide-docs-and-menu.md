# 189 — 가이드 문서 2종 + 어드민 "가이드" 메뉴

## 배경·의도 (사용자 요청, 2026-07-06)
스펙 188(산출물형 에이전트) 완주 후 "이 에이전트는 어떻게 만드나?" 논의에서 출발:
1. 문서가 **두 벌** 필요 — "일반사용자(노코드)"용과 "개발자"용 (사용자 교정: 노코드/코드 2버전).
2. 노코드 가이드는 **이 서비스를 모르는 사람이 이해**할 수 있어야 하고, **RAG·MCP 등록, 권한 설정,
   평가, 승인, 플레이그라운드 등 메뉴 설명**이 잘 들어가야 한다.
3. **스크린샷 포함** + **권한 설정 상세** 요청.
4. HTML 버전을 어드민 **"가이드" 메뉴**로 연결.

  에이전트 만들기→**권한 이해하기(세 층: 사람 역할/에이전트 붙이기/도구별 승인±오버라이드,
  "조이는 건 누구나, 푸는 건 관리자만", 실행까지 3단계 확인)**→Playground→평가→승인→막히는 곳.
