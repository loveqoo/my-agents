# 138 — 평가 2탄: 실행 이력 추이 + 런 비교 (회귀 가시화)

## 배경 / 왜
137로 시험·성적표가 생겼다. 2탄=**시간에 따른 변화**: 에이전트/프롬프트를 고친 뒤 "나빠졌나?"를
숫자·그림으로. 사용자: UI/UX 잘 고려(실사용 확인 예정).

## 설계
### 백엔드 (최소 — 조회 필터만)
- `GET /eval/runs?dataset_id=` 필터 추가(+limit 기본 50 유지). 비교는 기존 단건 성적표 2회 조회로
  프론트가 계산(신규 저장 없음).

### 프론트 (dataviz 스킬 적용)
1. **문제집 드로어에 "성적 추이" 섹션**: 이 문제집의 최근 런들 —
   - 미니 라인 차트(SVG, 단일 계열=범례 없음, 프라이머리 블루 검증 PASS, y 0~100%, 2px 라인+8px 점,
     은은한 그리드, 점 호버 툴팁: 일시·점수·통과/전체, 마지막 점만 직접 라벨=현재 점수).
   - error 런은 차트에서 제외하고 목록에 상태 태그로(색+라벨, 색 단독 금지).
   - 차트 아래 최근 런 목록(=표 뷰 역할, 클릭→성적표).
2. **실행 이력 탭**: 문제집 필터 Select + **비교 모드** — 런 2개 체크 선택(같은 문제집만) → "비교"
   버튼 → 비교 드로어:
   - 상단: 두 런 점수 요약(A→B, Δ%p).
   - 케이스별 표: 케이스명 | A 결과 | B 결과 | 변화(회귀=red 태그+아이콘 / 개선=green / 동일=무표기).
     **회귀가 눈에 먼저 들어오게** 회귀 행 우선 정렬.
   - assert 단위 diff는 행 펼침(어떤 기준이 새로 실패했나).

## 검증

  → 추이 차트 점 2개·마지막 라벨, 비교 드로어에서 해당 케이스 "회귀" 태그·assert diff 확인. UI/UX
  스샷 확보(사용자 확인용).
