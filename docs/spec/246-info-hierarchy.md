## 배경 (사용자 2026-07-08)

"예전보다 좋아졌지만 여전히 복잡해 보인다. **복잡한 데이터를 인정하고** 어떻게 더 잘 보여줄지 고민할

## 공통 문법 — 정보 3층 위계 (합의)

| 층 | 내용 | 노출 |
|---|---|---|
| 1층 | 정체성·상태(이름·종류·서빙 vN·초안·공개·비영속) | 항상 — 배지 한 줄 |
| 2층 | 관심사 하나(구성/버전·배포/공개·연동/운영) | **탭 — 하나만 렌더** |
| 3층 | 상세·진단(빈 값·식별자·환경 기록) | 요청 시 — 접기·툴팁·복사 강등 |

이후 화면 개편(승인 등)도 이 문법을 따른다.

## 에이전트 상세 적용

- **1층**: 헤더 배지 줄 — 서빙 vN(기존)+종류+초안 있음+public/private+A2A+비영속. agentId는 본문
  코드 → **복사 버튼+툴팁 강등**(canonical 표기는 공개·연동 탭의 IdRow가 보유).
- **개요 탭 = 요약 대시보드(지도)**: 상세 나열 대신 각 관심사의 **요약 한 줄**(연결: "도구 2 · 문서 1",
  버전: "서빙 v3 · 초안 v4", 운영: "👍12 👎2 · 최근 평가 94%") — 클릭하면 해당 탭으로 점프.
  페르소나 stale 알림 등 **행동 필요한 것만** 개요에 남긴다.
- **탭 전환**: 스크롤 점프(전부 렌더) → 활성 탭 하나만 렌더. 좌측 네비 유지(모바일 가로 스트립).
- **빈 값 접기**: 구성 탭에서 값 있는 표면만 행으로, 없는 표면은 "연결 없음: 문서 · 기억" 한 줄.
