# 274 — 모델·프롬프트 facet 공용화 (+ 에이전트 폼 chat 필터 버그 수정)

> 273 마감 기준("개념 편집 표면 전수 grep") 적용해 남은 facet 점검(사용자 요청)한 결과.
> 모델 = 3표면 자체 빌더 사본 + **진짜 버그 1건**. 프롬프트 = 참조/사본 패러다임이 갈려
> **노드·오버라이드 페어만** 공용화(에이전트 폼 참조 방식은 247 기준으로 통일 반려).

## 측정 (점검 결과)

**모델 — 편집 표면 3곳, 셋 다 자체 옵션 빌더**:

| 표면 | chat 필터 | 미등록 값 보존 |
|---|---|---|
| 에이전트 폼(AgentForm:160) | **없음 ← 버그** (주석은 "chat 모델로 구성") | 있음 |
| 노드 카드(AgentForm:263→NodeListEditor) | 있음 | 없음 |
| 오버라이드(OverridePanel:200) | 있음 | 있음 |

- **버그**: 에이전트 폼 Select에 임베딩 모델 노출 → 선택·저장 통과 → 런타임 해석은
  `kind=="chat"` 조회(chat.py:124)라 대화 시점 모델 미해석 실패. 244 "주석만 있고 가드 없음" 재현.

**프롬프트 — 편집 표면 3곳, 패러다임 분기**:
- 에이전트 폼(426) = 블록 이름 **참조** 저장(런타임 해석) — 통일 반려(저장 시맨틱이 다름).
- 노드(NodeListEditor:119-144) = **텍스트 작성** + 라벨 줄 "등록 페르소나에서 가져오기"(body 복사).
- 오버라이드(OverridePanel:369-393) = **텍스트 작성** + 별도 Field "페르소나 블록에서 채우기"(body 복사).
  → 노드·오버라이드는 같은 패턴 2중 구현.

## 변경

1. **`ModelFields.tsx`** (MemoryFields 271 패턴): `chatModelOptions(models)` 헬퍼(chat 필터, 단일 출처)
   + `ModelField`(라벨 '모델'+Select — 필터·**미등록 값 보존** 내장, hint/placeholder/필수 status prop).
   3표면 교체: 에이전트 폼(버그 소멸 — 임베딩 제외)·노드 카드(보존 로직 획득)·오버라이드.
   NodeListEditor prop `modelOptions` → `models`(새 노드 기본값도 chatModelOptions 첫 항목).
2. **`PromptFields.tsx`**: `PromptField`(라벨 줄에 "등록 페르소나에서 가져오기" 콤팩트 로더(learning 078
   세로 스택) + TextArea + hint). 노드('프롬프트', 필수 status)·오버라이드('시스템 프롬프트', 별도 Field
   2개 → 1구획으로 축약, hint "비워두면 저장된 페르소나가 그대로") 교체. 로더 key=name 통일.
3. 에이전트 폼 페르소나 참조 Select·mock+도구 경고(맥락 조건부)는 그대로(각자 소유).
4. **노드 카드 배치(사용자 지시, 실행 중 추가)**: 프롬프트 → 모델 → 단기·장기 기억 →
   도구·문서 → 이전 결과 받기·응답 형식 순서로 재배치(기억을 에이전트 폼 271 구획처럼 나란히,
   단기가 받기/형식 사이에 끼어 있던 것 해소). e2e가 DOM 순서를 단언.

## 완료 조건 (측정 가능)

1. chat 필터·미등록 보존 정의 = **ModelFields.tsx 1곳** (`kind === 'chat'` 옵션 빌더 grep — admin/src
   에서 에이전트 편집용은 1곳, ProviderModelView의 표시용 kind 분기는 무관).
2. 페르소나 body 복사 로더 구현 = **PromptFields.tsx 1곳**, 소비처 노드·오버라이드 2곳.
3. **버그 수정 실증(e2e)**: 등록된 embedding 모델명이 에이전트 폼 모델 옵션에 **안 나옴**(수정 전엔 나옴).
4. 기능 왕복: 노드·오버라이드에서 페르소나 로더 선택→TextArea에 body 채워짐, 편집·저장/적용 배선 유지.
5. 미등록 모델 보존: 노드에 ghost 모델 저장분 편집 시 선택 유지(3표면 공통 획득).
6. tsc 0 + 269/271/272/273 무회귀.
