# 스펙 215 — 에이전트 필터 드롭다운 라벨 잘림 수정

## 배경 (사용자 실사용 지적 2026-07-07, 스샷)

에이전트 목록의 필터 Select(소유·소스 등)에서 드롭다운 옵션 글자가 말줄임(…)으로 잘렸다:
"private · 타인 (…", "internal (UI …". 원인 = antd Select 팝업이 기본으로 **트리거 폭에 맞춰짐**
(`popupMatchSelectWidth` 기본 true) → 트리거(130~140px)보다 긴 옵션 라벨이 잘림.

## 변경 (admin/src/admin/views/AgentsView.tsx)

- 4개 필터 Select(정렬·소유·소스·상태) 모두에 `popupMatchSelectWidth={false}` 추가.
  → 팝업이 **내용폭**에 맞춰 열려 전체 라벨 노출. 트리거 폭(130~140)은 그대로(가로 배치 유지).
- 문구·옵션·값 불변(표시 폭만).

## 완료 기준 (측정)
- 브라우저: 소유/소스 드롭다운 열어 옵션에 말줄임(…) 0개, "private · 타인 (숨김 해제)"·
  "internal (UI 구성)" 전체 노출. tsc 0.

## OUT
- 다른 뷰의 Select는 대부분 width:'100%'(잘림 없음). 유사 잘림이 보고되면 같은 처방 적용.
