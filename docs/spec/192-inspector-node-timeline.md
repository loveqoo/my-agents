# 192 — 인스펙터 개편: 단계(노드)별 실행 타임라인

## 배경 (실사용 문의)
현재 인스펙터는 **자원 종류별 요약**(메모리 / 문서검색 / MCP / 브로커를 각각 별도 섹션)이고, 맨 아래
"LangGraph 경로"는 노드 이름 + ms + 상태요약만 보여준다. 사용자가 보고 싶은 것은 **"어느 단계에서
무엇을 어떻게 호출했고 결과가 어땠나"** 다:
- 어느 단계에서 메모리를 무슨 쿼리로 조회했고 몇 건 회상했나
- 어느 단계에서 RAG를 어떤 단어로 몇 번 조회했고, 컬렉션별 커트라인이 얼마라 **어떤 문서를 썼고
  어떤 문서를 (커트라인 미달로) 못 썼나**
- 어느 단계에서 어떤 도구를 호출했고 결과가 뭐였나

즉 **자원 축 → 실행(노드) 축**으로 뒤집는 개편. 추가로 **드로워(384px)가 비좁다** → 넉넉한 컴포넌트·
레이아웃 필요(컴포넌트 선택은 위임받음, 2026-07-06).

## 사용자 결정 (2026-07-06)
- 구조: **단계별 타임라인으로 완전 대체**(자원별 섹션 제거, 노드 축이 주역).
- 공간: 드로워가 비좁음 → 다양한 컴포넌트·확장 레이아웃 고려(위임).
- 커트라인 미달 문서("이용하지 못한")까지 표시.

## 설계

### A. 노드 축 데이터 모델 (프런트 조립 — "이벤트를 노드에 귀속")
trace를 **노드별 이벤트 리스트**로 재조립한다. 귀속 규칙(추측 아님 — 기존 데이터 근거):
- **브로커(조율형) 경로**: `brokerCalls[].node`(=`broker_invoke:rag:X`/`broker_invoke:mcp:X`) → 그 노드에
  귀속(이미 node 필드 보유, 스펙 130).
- **직접 경로**: `calls_sink`(t.mcp)는 node 필드가 없다. 직접 그래프는 `retrieve_memory → tools →
  call_model` 선형이라 **타입으로 귀속**: 메모리 회상 → `retrieve_memory`, 모든 rag/mcp 호출 → `tools`,
  응답 토큰 → `call_model`. (ReAct 다중 tools 반복은 한 `tools` 노드로 접힘 — 현 graph_path 합성과 동일,
  per-iteration 귀속은 후속 빚.)
- 노드 스파인 = `t.graph`(GraphNode[] {node, ms, summary, parallel}).

### B. 각 노드에 붙는 상세 (기존 컴포넌트 재사용 + 신규)
- `retrieve_memory`: 회상 쿼리(«...») + 회상 건수 + 결과 행(기존 메모리 섹션 렌더 재사용).
- `tools`(직접) / `broker_invoke:rag:*`(조율형): **RAG 검색 카드** — 검색어 + 컬렉션 + 커트라인 + 히트
  카드(스펙 191 재사용). **used/dropped 구분**: 커트라인 통과=사용 / 미달=제외(회색·"커트라인 X 미달").
- `tools` / `broker_invoke:mcp:*`: MCP 도구 호출 카드(서버.도구 + args + result, 기존 재사용).
- `call_model`: 토큰(in/out) + (있으면)상태요약.
- `interrupt`/승인/폼: 기존 approval/artifact 표시.
- 이벤트 없는 노드(`__start__` 등): 이름 + ms만(접힌 상태).

### C. 커트라인 미달 문서 표시 (백엔드 소규모 추가)
현재 필터(`_apply_min_scores`)는 미달 히트를 **버려서** trace에 안 남는다 → "이용 못한" 문서를 못 보여줌.
- **변경**: 에이전트 경로(build_rag_tool·RagProvider)에서 검색은 top_k 전체를 받고, **커트라인 적용을
  "드롭"이 아니라 "표시(belowCutoff 플래그 + cutoff 값)"로**. 에이전트에게 가는 결과(format_rag_hits)는
  여전히 **통과분만**(에이전트는 미달 문서를 안 봄 — 필터 의미 유지). trace의 hitsDetail은 **전부**(플래그
  포함) 싣는다.
- 즉 검색 코어는 순위·top_k만, **커트라인 판정은 에이전트 경로에서 used/dropped 분리**(shared core에서
  per-agent 커트라인 빼내 개념 정리). rag.py 시험 엔드포인트·eval_runner(커트라인 미전달)는 무영향.
- hitsDetail 항목에 `belowCutoff: bool` + (해당)`cutoff: float` 추가. 마스킹·캡은 그대로(스펙 191 봉합).

### D. 공간·레이아웃 (드로워 비좁음 해결)
- **antd `Timeline`**을 노드 스파인으로(세로 점·연결선·색). 각 노드 = TimelineItem, 상세는 `Collapse`로
  펼침(기본: 이벤트 있는 노드만 펼침).
- **탭 분리**(`Tabs`): ① **실행 흐름**(노드 타임라인, 주역) / ② **프롬프트·설정**(전송 프롬프트·오버라이드 —
  턴 메타라 노드 이벤트 아님). 상단에 지연시간·토큰 메트릭 유지.
- **전체화면 확대**: 드로워 헤더에 "확대" 버튼 → 인스펙터를 **넓은 오버레이(Modal, 90vw)**로 열어 깊은
  디버깅 시 가로 공간 확보. 좁은 드로워는 빠른 일별용으로 유지(기존 `fullWidth` 경로 재활용).

## 검증 (사다리)
- **단위**: (백엔드) 커트라인 판정 used/dropped 분리 — 에이전트 결과는 통과분만, hitsDetail은 전부+플래그
  (경계·미설정·비정상값). trace 노드 귀속 헬퍼(프런트 순수 함수)가 이벤트를 옳은 노드에 붙이는지(직접/
  조율형/혼합).
- **e2e**: 플레이그라운드 실행(직접 RAG + 커트라인) → 인스펙터 타임라인에 `retrieve_memory`/`tools`/
  `call_model` 노드 + tools 노드 아래 검색어·used·**dropped(미달)** 노출 확인(스샷). 전체화면 확대 동작.
  조율형(브로커) 턴도 broker_invoke 노드 귀속 확인.
- **무회귀**: 기존 인스펙터가 보이던 정보(오버라이드·전송프롬프트·승인·A2A)가 새 구조서 다 접근 가능한지
  체크리스트 · verify_191(마스킹·필터) · admin tsc 0.

## RBAC 경계 (트리거 판정)
- **트리거 아님**: 표시 재구성 + RAG 커트라인 표시 방식 변경. 유저별/테넌트 데이터·소유권 헬퍼 미접촉.
  trace 누출 규율(마스킹·캡)은 스펙 191 그대로 유지(dropped 문서도 동일 마스킹). 새 쓰기 입구 0.

## 경계
- 직접 경로 이벤트의 노드 귀속은 **타입 기반 휴리스틱**(그래프 형태 가정) — per-call 정확 귀속(ReAct
  다중 반복 구분)은 백엔드가 calls_sink에 node를 실어야 가능, 후속 빚.
- 전체화면은 오버레이(Modal) 확대 — 별도 라우트/영속 뷰 아님(스펙 126 인라인과 다른 축).

## 후속 (2026-07-06) — messages 델타를 건수 → role+프리뷰
실사용 문의: `plan` 노드는 요약에 계획 문자열이 나오는데 `execute` 노드는 "메시지 1건"만 나온다 —
왜 내용을 안 보여주나. 원인: `_summarize_node_update`가 `messages` 키만 **의도적으로 건수만**
냈다(스펙 086 — "채팅에 이미 스트림됐으니 중복 방지"). 하지만 인스펙터 타임라인과 채팅 버블은 **다른
패널**이라 나란히 안 보여, 사용자에겐 중복이 아니라 **정보 부재**였다.
- **변경**: `messages` 델타도 앞 `_MSG_PREVIEW_N`(3)건을 `role: «본문 프리뷰»`(`_MSG_PREVIEW_CAP`=160자)로,
  나머지는 `(+N건)`. 086 불변식 유지(마스킹은 캡 이전 큰 cap으로 무절단·잘림은 `_cap` 정직표기·
  비정상 메시지 fail-closed). role은 `_msg_role`이 청크형 type도 소문자 접두로 방어(ai→assistant 등).
- **의도된 시맨틱 변경**: verify_086 U3/H2가 "messages는 건수만"을 단언했으므로 **새 계약으로 재작성**
  (빨강≠회귀). 검증=verify_086 단위+실통합(plan_execute 실행 execute summary=발화 프리뷰)·브라우저 스샷.
