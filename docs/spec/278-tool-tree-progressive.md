# 278 — 도구 트리 점진 공개: 아코디언 복원 + 1 depth 초기화 + 블릿 수리 + 도구 설명

> 사용자 피드백(277 직후): ①아코디언 같은 뷰가 mcp에서 제거됨(전엔 PickerGroups 접이식) ②트리
> 블릿(스위처)이 동작 안 해 접을 수 없음 ③처음 열 때 1 depth(서버만) — 한 번에 많이 보여주면 인지
> 부담 ④mcp 정보를 리치하게 — **도구 설명 없이 자유롭게 고를 수 없다**.

## 근인 (정직)

277의 ToolTree가 `expandedKeys`를 **상수(전체)로 고정**하고 `onExpand`를 빈 함수로 둠 — 스위처가
죽고 항상 전부 펼쳐짐(②③의 원인이 같음). 접이식 래퍼도 PickerGroups→트리 전환에서 떨어져 나감(①).
설명 데이터(toolsMeta)는 카탈로그에 이미 있는데 안 씀(④).

## 변경 (ToolTree v2 — 점진 공개)

1. **아코디언 래퍼**: 트리를 antd Collapse 단일 패널("도구" + 선택/전체 배지)로 감싼다 —
   PickerGroups와 같은 룩(기본: 선택 있으면 펼침·없으면 접힘). 세 표면 공통.
2. **1 depth 초기화 + 블릿 수리**: `expandedKeys`를 상태로(초기 `[]`=서버만), `onExpand`가 상태
   갱신(스위처 동작). 검색 중엔 매칭 서버 자동 확장(검색 해제 시 사용자 상태 복원).
3. **도구 설명(리치)**: 리프 타이틀 = 도구명 + toolsMeta[tool].description(뮤트·ellipsis).
   서버 타이틀 = 서버명 + "도구 n개"(뮤트). Server 타입에 toolsMeta 추가(카탈로그가 이미 보유).

## 완료 조건 (측정 가능)
1. 폼 초기: 도구 아코디언 접힘(선택 없을 때) — 리프 안 보임(e2e).
2. 아코디언 열면 서버만(1 depth) — 리프 안 보임(e2e).
3. 스위처(블릿) 클릭 → 리프 노출/재클릭 → 접힘(동작 수리, e2e).
4. 리프에 설명 노출(toolsMeta 있는 도구, e2e).
5. 검색 입력 → 매칭 서버 자동 확장(e2e).
6. 277 기능 무회귀(부모/자식 체크·저장 왕복— 형제 e2e 확장 후 상호작용으로 갱신) + tsc 0 + 오버플로 0.
