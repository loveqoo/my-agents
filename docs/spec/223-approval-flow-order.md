# 스펙 223 — 승인 처리됨 카드: 요청→처리 흐름 순서 + 라벨 공백

## 배경 (사용자 실사용 지적 2026-07-08)

1. 처리됨 카드가 [처리자] [처리 시각] [요청] 순 → 시간 흐름과 반대(처리→요청). **요청 → 처리**로.
2. "처리 시각" 라벨 뒤 공백을 명시적으로 보장(값과 붙어 보이지 않게).

## 변경 (admin/src/admin/views/ApprovalsView.tsx — HistoryCard)

- 메타 3줄 순서를 **요청(시각) → 처리자(본인/관리자) → 처리 시각**으로 재배열(위=요청, 아래=처리).
  요청 줄에 clock 아이콘 부여, quaternary(흐린색) 제거해 tertiary로 통일(흐름 시작이 안 흐리게).
- 라벨 뒤 공백을 `{' '}`로 명시(요청·처리 시각 둘 다) — 값과의 구분 보장.

## 검증
- 브라우저 처리됨 탭: 카드 텍스트가 "요청 …" → "본인/관리자 처리" → "처리 시각 …" 순. 라벨 뒤 공백. tsc 0.
