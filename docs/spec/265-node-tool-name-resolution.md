# 265 — 노드 도구 이름 해석 버그: 조용한 미바인딩이 도구 환각을 불렀다 (스펙 264 후속)

## 배경 (사용자 지적이 잡은 버그)
264 테스트 2회 모두 위키 도구가 안 불렸는데 "모델 재량"으로 접고 그린 선언했다. 사용자: *"위키
찾아서 계획 세워야 하는데 위키를 찾지 않았어. 제대로 테스트해줘."* — 도구 발화를 **필수 단언**으로
바꾸자 실체가 드러났다: 모델이 "wiki_search를 통해 검색한 결과…"라고 **말만 하고 실호출 0건**
(트레이스 mcp=[], 도구 노드 미발화) — **도구 사용 환각**.

## 근인 (2단 프로브로 확정)
- (a) 실 `build_mcp_tools`의 도구 이름 = **`web-fetch__wiki_search`**(`_safe_name` = `서버__도구`,
  비허용문자 `_` 치환·60자 캡). 노드에 저장된 건 민이름 `wiki_search` → 엔진 `by_name` 정확 매칭 0
  → **도구가 아예 미바인딩**(조용히). 모델은 프롬프트의 "wiki_search를 호출하라"만 보고 호출한 척.
- (b) 제대로 바인딩하면 모델(qwen3.6-35b)은 정상적으로 tool_calls를 냄 — 모델 문제 아님.
- 원류: 프론트 노드 도구 옵션이 민이름을 value로 저장(259) — UI·런타임 이름 체계 불일치. 저작 e2e는
  저장 왕복만 보고 실행은 도구 없는 노드로만 돌려 이 미스매치가 안 잡혔다.

## 수정
1. **엔진 회복력**(pipeline.py): `_resolve_tool` — 정확 일치 우선, 실패 시 **무모호 접미 매칭**
   (접미 후보 유일할 때만). 모호(두 서버 동명 도구)면 스킵(정직 — 아무거나 바인딩 금지). 후보는 전부
   ctx.tools(RBAC 스코프) 안이라 권한 영향 0. 기존 민이름 저장분 자가치유.
2. **프론트 정합**(AgentForm): 노드 도구 옵션 value = 런타임 이름(`safeToolName` — 백엔드 `_safe_name`
   미러, 변경 시 함께). 서버 간 동명 도구의 Select value 충돌도 해소. 풀 파생은 런타임 이름+민이름 둘 다
   수용(구저장분).

## 검증
- **단위** `verify_265_tool_names.py` 5/5: 정확 일치·접미 자가치유·모호 스킵·풀 밖 무시(권한 상승 0)·
  무접두 도구(search_documents) 정확 일치.
- **실모델+실 MCP**(`verify-plan-demo-wiki.mjs`, 도구 발화 **필수 단언**): 그래프
  `계획→실행→실행__tools→실행→실행__tools→실행`(도구 루프 2회), mcp 기록 `wiki_search: ok`+
  `wiki_page: ok`, 답변이 실제 위키 근거(마틴 파울러 명명·식물 유래 — 문서를 읽어야 나오는 내용). 10.2s.
- 무회귀: 259(15)·260(10)·261(14) + tsc 0.
- **RAG 축**(사용자 요청 후속, `verify-pipeline-rag.mjs` — 필수 단언): 노드형 1노드(tools=
  ['search_documents'], docs-kb, 실모델) → 그래프 `문서답변→문서답변__tools→문서답변`(도구 루프 발화),
  호출 기록 `{server: rag, tool: search_documents, status: ok, args: {query, top_k: 4}}`, 답변이 docs-kb
  청크 원문("가입 페이지에서 이메일과 비밀번호…") 그대로 근거. 4.0s ALL GREEN. search_documents는
  무접두라 정확 일치 경로(T2b 예측대로) — MCP(접두명)·RAG(민이름) 두 이름 체계 모두 실발화 검증 완료.

## 교훈 (회고 240)
- "그린인데 핵심 행동이 한 번도 발화 안 됨"은 그린이 아니다 — 데모의 존재 이유(위키 검색)는 재량으로
  접지 말고 필수 단언으로.
- 조용한 미바인딩 + "도구를 부르라"는 프롬프트 = 모델이 부른 척 환각하는 조합. 미바인딩은 크래시가
  아니라 그럴듯한 거짓말로 나타난다.
- 이름 체계가 계층마다 다르면(UI 민이름 vs 런타임 접두명) 접점에 정규화·미러를 명시하라.
