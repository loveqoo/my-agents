# 스펙 222 — 승인 내역 시각 표기 (원본 ISO → 날짜+시각 친화)

## 배경 (사용자 실사용 지적 2026-07-07~08)

1. 승인 카드가 원본 ISO(`요청 2026-07-05T05:08:19.918093+00:00`)를 날것으로 렌더 → "너무 길다".
2. `fmtTime` 적용했더니 오늘이 아니면 시각을 떼고 날짜만("7월 5일") 보여줌 → "시간까지는 보여줘야 합니다"
   (승인=감사 성격이라 정확한 시:분:초가 필요).

## 변경

- **format.ts에 `fmtDateTime` 추가**: 항상 날짜+시:분:초(24h). 올해=`M월 D일 HH:MM:SS`, 그 외=`YYYY. M. D. HH:MM:SS`.
  ISO 아님·빈 값 처리는 `fmtTime`과 동일. (`fmtTime`은 목록·총계용으로 유지 — 오늘이 아니면 시각 생략.)
- **ApprovalsView 3곳**(대기 헤더 요청시각·처리됨 카드 처리시각·요청시각) → `fmtDateTime`.
  `resolvedAt`은 없을 수 있어 `fmtDateTime(x) || '—'`.

## 검증
- 브라우저 처리됨 탭: `요청 7월 5일 20:29:50`(날짜+시:분:초), 원본 ISO 0. tsc 0.
- 타 뷰 원본 ISO 렌더 스캔 0건(approvals가 유일 offender).

## OUT
- `fmtTime`(목록/총계)은 그대로 — 오늘 아니면 시각 생략이 그 문맥엔 적절.
- 메모리 '생성' 컬럼 등 이미 포맷된 표기는 불변.
