# 스펙 254 — 엔티티 검색 시험 히트 카드 정돈 (사용자 실기기 불편 접수)

## 문제 (2026-07-09)
엔티티 임베딩 검색 결과 카드가 임베딩 직렬화 원문을 그대로 출력 — 빈 키 라인(full_path:,
default_value: 등)이 라벨만 차지하고, 히트당 세로 8줄+, 하단에 raw JSON(meta) 상시 노출.
"빈 값도 자리 차지 금지"(246 문법) 위반이 검색 시험 카드에 잔존.

## 변경 (정직성 보존 + 노이즈 접기)
- **key: value 라인 형식 감지 시 구조화 렌더**(parseEntityText): 값 있는 필드만 라벨 고정폭
  2열로, **빈 필드는 이름만 모아 한 줄**("빈 필드: full_path · description · …" — 무엇이 비었는지는
  보임). 형식이 아니면(문서 청크) 원문 그대로(무회귀).
- **meta = null 제외 key=value 칩**: raw JSON({"label_cate_id":null,…}) 대신 `sql_filter_id=3` 칩
  나열 — 괄호·따옴표·null 노이즈 제거, 원본 행 특정 축(스펙 149)·실값 원칙은 유지.

## 검증
- 사용자 케이스 재현(entity 컬렉션+빈 필드 jsonl 시드) e2e 8/8: 값 필드 표·빈 필드 한 줄·
  null 제외 칩·오버플로 0 × 데탑/모바일. 시드 정리 완료. tsc 0.
