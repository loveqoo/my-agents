# 스펙 252 — RAG 컬렉션·평가 화면 점검·수정

## 배경 (사용자 지시, 2026-07-09)

두 화면 모두 복잡도 표면 수치는 정상(0.9x)이나, 245 진단이 명시한 사각 = **오버레이 속 복잡도**
(평가: 문제집 드로어에 실행 폼·추이·케이스 편집·비교 겹겹 / RAG: 문서·검색 드로어). 250에서 중복은
기정독 — 이번엔 **문법 전반**(3층 위계·식별자 강등·값=상태·탭 규칙·오버플로 상태 축) + 오버레이.

## 방법 (3중 — 자가검증 회피)
1. deep-reasoner: CollectionsView·EvalView(+EvalMatrix·EvalTrend·RetrievalTest류) 코드 정독 —
   문법 위반 후보 열거(file:line·확신도·처방).
2. 메인: 런타임 육안 — 화면 + **주요 오버레이 열린 상태**(문제집 드로어·문서/검색 패널)를
   데탑·모바일 캡처, 오버플로 실측(빈 상태 아닌 데이터 상태).
3. 교차 판정 → 명백 위반은 수정, 회색지대는 근거와 함께 보고.

## 완료 조건
- 두 화면과 그 오버레이 전부 육안 판정 완료, 확정 위반 수정 + e2e 무회귀.
