# 스펙 239 — 에이전트 생성/수정 폼 위저드 개편

## 배경 (사용자 2026-07-08)

"지금도 어렵습니다. 설정이 명확하고 간편해야 합니다." — 238의 부분 개선으로 부족. 한 모달에 결이 다른
결정(정체성·연결·튜닝)이 섞이고, 필수/선택 구분이 없으며, 560px에 스크롤만 길어졌다.

## 사용자와 합의한 구조 (3라운드 논의)

1. **그릇**: 단계형 위저드, **생성·수정 한 폼**(수정은 단계 자유 이동). 넓은 모달 **~760px**(모바일 전체폭).
2. **4단계**: ① 정체성 → ② 하는 일 → ③ 세부 → ④ 요약·확인.
3. **생성 규칙**: 마지막(요약) 단계까지 가야 생성 버튼 — 빠짐없이 훑어보게 강제(명확 우선).
4. **수정 규칙**: 단계 자유 이동, **저장은 요약 단계에서만**(생성과 동일 규칙 — 무엇이 바뀌는지 보고 저장).

## 단계 구성

| 단계 | 내용 | 검증(다음 조건) |
|---|---|---|
| ① 정체성 | 이름·설명·종류(rich)·모델(+mock 힌트)·페르소나·저장 방식(영속/비영속) | 이름 필수+규칙(148) |
| ② 하는 일 | 종류별: 직접=도구·문서·기억(+RAG 최소 유사도) / 조율형=위임 대상 / 산출물형=모을 항목 | 산출물형=유효 필드 ≥1 |
| ③ 세부 (선택) | Temperature·채팅 히스토리·대화 저장·추천 명령어 — 기본값 그대로면 그냥 통과 | 없음 |
| ④ 요약·확인 | 설정 요약 카드(섹션별) + 각 섹션 "수정" 클릭 → 해당 단계 점프. 생성/저장 버튼 여기만 | — |

- 기존 규칙 전부 승계: consumes 게이트(206)·비영속 잠금/자동해제(237/238)·미선택-잠금·mock 힌트.
- 데이터 모델 무변경(AgentFormData/config 그대로) — **순수 표현 개편**(회귀 반경 축소).
- 요약 카드: 정체성(이름·종류·모델·저장방식) / 하는 일(연결 카운트+이름 나열) / 세부(기본값과 다른
  항목만 표시, 전부 기본이면 "기본값 사용").

## 진행 규칙
- 생성: 순차(다음/이전), **방문한 단계**는 스텝 클릭으로 재이동 가능. 요약 도달 시 "에이전트 생성".
- 수정: 4단계 전부 클릭 이동 가능(값이 이미 완전), 저장 버튼은 요약에만.
- 단계 이동 시 스크롤 상단 복귀. 모바일: Steps 축약 표시(antd responsive).
