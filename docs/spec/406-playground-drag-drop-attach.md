# 406 — 플레이그라운드 드래그&드롭 첨부(404/405 입구 확장)

> 상태: **완료** · 2026-07-19
> 발단: 개발자 제안 "문서를 드래그 드랍하면 2가지 옵션 메뉴" — 클립 버튼과 같은 두 갈래
> (이번 대화만/지식으로 저장)를 드롭으로도. 백엔드 0줄(기존 onAttachFiles/onAttachKnowledge 재사용).

## 사용자 경험

파일을 채팅 영역 위로 끌면 **드롭 오버레이**("여기에 놓아 첨부")가 뜨고, 놓으면 **선택 모달**:
[이번 대화만 첨부] / [지식으로 저장 (RAG)] 두 버튼. 선택 즉시 기존 흐름(404 칩 / 405 컬렉션
픽커)으로 합류. A2A 모드에선 드롭 무시+안내. 파일이 아닌 드래그(텍스트 선택 등)는 무반응.

## 구현(DebugChat 한 곳)

- P1 드롭 존: 채팅 영역 컨테이너에 dragover/dragleave/drop — `dataTransfer.types`에 Files 있을
  때만 오버레이(중첩 dragenter 카운터로 깜빡임 방지). 드롭 시 선택 모달 {files} 오픈.
- P2 선택 모달: 두 버튼 → onAttachFiles(files) / onAttachKnowledge(files) 라우팅(캡·다중 파일
  규칙은 기존 흐름이 소유 — 여기선 위임만).
- P3 검증: 브라우저 e2e — DataTransfer 합성 드롭 → 모달 → "이번 대화만" 경로로 칩+응답 토큰
  (404 흐름 관통), 1280px(+390px 스냅샷). tsc·make test 무회귀.

## OUT

- 드롭 시 즉시 업로드(선택 생략) — 두 갈래 의도 선택이 이 기능의 본질.
- 채팅 밖(전체 앱) 드롭 존.
