# 405 — 첨부→지식 저장(B안: 플레이그라운드에서 RAG 인제스트)

> 상태: **완료** · 2026-07-19 (P1~P4 + codex P1 2건·P2 3건 반영)
> 발단: 스펙 404(A안 스터핑) 완료 후 개발자 "B안 매력적" — 같은 클립 입구에서 "이번 대화만 /
> 지식으로 저장"을 가른다. **백엔드 신규 코드 ~0**: 인제스트(POST /collections/{cid}/documents)·
> 세션 오버라이드(vectorTables ∈ _OVERRIDE_ALLOWED, 스펙 287)·검색 코어 전부 기존 재사용.

## 사용자 경험

클립 → 파일 선택 → **"이번 대화만(기본) | 지식으로 저장"** 선택. 지식으로 저장이면:
컬렉션 픽커(기존 document 컬렉션 + "새 컬렉션"(이름 입력 — 기본 임베딩 모델)) → 업로드 →
칩이 "인제스트 중…"(폴링) → ready 되면 "지식 저장됨" 칩 + **이번 세션에 자동 배선**(오버라이드) →
바로 질문하면 검색 도구가 그 문서를 찾고, 인스펙터에 rag 히트가 보인다.

## 설계 결정

- **저장 위치 = 기존 RAG 컬렉션**(세션 임시 컬렉션 신설 기각): 이미 있는 컬렉션 화면·정리·재인덱싱
  도구를 그대로 상속 — 관리 표면 신설 0. 문서는 영구 자산(다른 에이전트·다른 세션서도 배선 가능).
- **배선 = 세션 오버라이드(vectorTables)**: 저장 에이전트는 불변(스펙 370 버전 시스템을 안 건드림 —
  편집→새 버전→오픈 의식 회피). 이번 세션에서 즉시 검색되고, **영구 배선은 기존 에이전트 편집
  UX로**(정직한 경계 — 다음 세션엔 오버라이드가 안 남는다는 것을 칩/안내에 명시).
- **캡·가드 = 기존 인제스트 그대로**(이름 규칙 148·raw 캡·임베딩 차원 가드) — 신설 없음.
- ready 전 전송은 막지 않되 칩이 상태를 정직 표시(검색 히트는 ready 후부터).
- A2A 루프백 모드 비활성(404와 동일).

## 구현(프론트 중심)

- **P1 선택 UI**: 클립 클릭 시 드롭다운(이번 대화만/지식으로 저장) — 404 흐름은 무변경 기본값.
- **P2 지식 경로**: 컬렉션 픽커 모달(listCollections 재사용 + 인라인 새 컬렉션 생성) → 업로드
  (기존 documents API) → 문서 status 폴링 → 칩 상태 전이(인제스트 중→지식 저장됨/실패).
- **P3 세션 배선**: 오버라이드 패널의 vectorTables에 해당 컬렉션 추가(이미 적용된 오버라이드와 병합,
  중복 방지) — 인스펙터 trace.overrides·ragCollections로 표면화(기존 필드).
- **P4 검증**: 브라우저 기능 e2e(첨부→새 컬렉션 생성→ready 대기→질문→**응답이 문서 근거+인스펙터
  rag 히트 1+**·다른 세션엔 배선 없음 확인) 1280/390px. 백엔드 무변경이라 verify 신규는 없음 —
  make test SUITE_OK(배타)+metrics-fast(tsc 포함)로 무회귀.

## OUT

- 영구 배선 자동화(에이전트 저장본 수정 — 버전 의식과 함께 별도).
- 세션 임시 컬렉션·자동 정리 정책(기각한 갈래).
