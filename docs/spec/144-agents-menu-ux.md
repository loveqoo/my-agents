# 144 — 에이전트 메뉴 UX 보완 1 (실사용 피드백 3건)

## 배경
사용자 실사용 테스트 모드 첫 보고(2026-07-03). 세 가지 마찰:
(1) 편집 완료 후 리스트로 떨어짐 — 방금 편집한 에이전트의 드로워로 복귀해야(활성화 흐름).
(2) 드로워의 "테스트" 버튼이 토스트만 — 플레이그라운드로 이동하는 걸로 오인(실제 그래야 맞음).
(3) 리스트: 좁으면 컬럼이 숨음(hideBelow) — 최대한 다 보여야. 검색 없음. 정렬 기준 불명.

## 설계
1. **편집 → 드로워 복귀**: openEdit이 출발 에이전트 id를 기억, 저장/취소 시 setDetailId(그 id)
   — 편집 후 바로 "활성화" 누를 수 있는 동선. 신규 생성은 기존대로(리스트 + 새 행).
2. **테스트 = 플레이그라운드 이동**: AdminShell에 요청 상태 추가 — AgentsView가
   onOpenPlayground(agentRowId) 호출 → setView('debug') + Playground에 initialAgentId 전달
   → 에이전트 목록 로드 후 1회 자동 선택. 토스트 제거(진짜 액션으로 대체).
3. **리스트 개선**: hideBelow 전부 제거(DataTable은 가로 스크롤+우측 고정 지원 — 접는 대신
   스크롤). 이름/모델/소스 검색 Input. 정렬 명시: Select(이름순↑/최근 등록순) 기본=이름순.

## 검증
- e2e(fast-worker): ①편집 저장→같은 에이전트 드로워 복귀+활성화 버튼 노출 ②테스트 클릭→
  플레이그라운드 화면+그 에이전트 선택됨 ③검색 타이핑→행 필터·정렬 전환. tsc. codex 간이.

## 비목표 (OUT)
- PagedListShell 서버 페이지네이션 이식(에이전트 수 적음 — 클라 필터로 충분), 컬럼 커스텀.
