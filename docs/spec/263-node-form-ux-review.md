# 263 — 노드형 폼 UI/UX 재검토: 요약 정직화 + 안내 문구 합류 (스펙 259 다듬기)

## 배경
사용자 요청(2026-07-09): "노드형 에이전트 설정의 UI/UX를 다시 검토해달라. 고칠 게 없으면 없다고 해도
된다." → 상태 트리(retrospect 229)로 5개 상태를 캡처해 육안+수치 검토: ①정체성(노드형) ②하는 일 빈
상태 ③노드 2개+JSON 펼침 ④요약 ⑤모바일 360px.

## 검토 결과
**양호(변경 없음)**: 빈 상태 안내+다음 비활성 게이트 · 노드 카드(번호 배지·↑↓·삭제·페르소나 가져오기·
맥락/출력형식 Segmented+설명·JSON 필수 키 펼침) · 모바일 가로 오버플로 0(수치)·세로 스택.

**결함 2건(수정)**:
1. **요약 거짓 확인(중요)** — 요약 정체성 카드가 노드형에서도 "모델 mock-llm·페르소나 calm-sre"를 1급
   표시. 노드형은 페르소나 미사용(노드가 각자 프롬프트)·모델은 노드 폴백뿐인데, 사용자가 정하지 않은
   숨은 기본값이 정체성처럼 보임(codex 239 #1 "요약 축소=거짓 확인"의 쌍대: 무관 값 표시도 거짓 확인).
2. **안내 문구 위치·중복(사소)** — "노드형은 노드마다…" 떠 있는 문구가 원인 필드(종류)보다 위(옛 모델/
   페르소나 그리드 자리)에 있고, 종류 아래 typeDesc와 사실상 중복. 고유 정보는 "다음 단계에서 추가"뿐.

## 수정 (AgentForm.tsx, 표시만)
- 요약 정체성: 노드형이면 모델/페르소나 행 대신 **"모델·프롬프트: 노드마다 설정 — 아래 처리 단계 참고"**.
- 처리 단계 행에 노드별 모델 병기: `노드1(mock-llm) → 노드2(mock-llm)` — 위 포인터가 실제로 답이 되게.
- 떠 있는 안내 문구 제거, 종류 필드 아래 설명에 합류: typeDesc + " 노드는 다음 \"하는 일\" 단계에서
  추가합니다."

- 무회귀: shot-pipeline-259 왕복 전부 그린(단계0 체크는 새 문구로 갱신) + tsc 0.
