# 275 — 노드 카드 접기/펼치기 + 접힘 헤더 요약

> 사용자 요청: "노드를 아코디언처럼 접고 펼 수 있으면 좋겠습니다. 노드 작성을 마치고 접으면
> 헤더에 노드 설정 정보를 간략히 보여주면 좋고요." — 노드가 2~3개만 돼도 카드가 길어져
> 파이프라인 전체 흐름이 한눈에 안 보인다. 접기+요약으로 개요↔상세를 오가게 한다.

## 설계

- **antd Collapse**(폴더 규칙: 접이식=Collapse) — 노드마다 단일 아이템 Collapse 하나(노드 사이
  ↓ 연결 시각은 유지). `collapsible="icon"`으로 **아이콘만 토글** — 헤더의 이름 Input·버튼 클릭이
  접힘을 오토글하지 않게(스펙 123 함정 회피).
- **헤더(label)**:
  - 펼침: 지금처럼 [번호 배지] + 이름 Input.
  - 접힘: [번호 배지] + 이름(없으면 "노드 N") + **요약 한 줄**(모델 · 도구 n · 문서 n · 기억 ·
    받기/형식 비기본값만) + 프롬프트 앞부분(뮤트, ellipsis). **미완성(프롬프트/모델 빈값)이면
    "작성 필요" 빨간 Tag** — 접혀도 저장 게이트 원인이 보이게.
  - 요약 줄은 `overflow hidden + ellipsis`(모바일 오버플로 0 유지).
- **extra**: ↑↓·삭제 버튼은 접힘/펼침 무관 항상(순서 조정에 펼칠 필요 없게).
- **기본 상태**: 편집 열람 시 전부 접힘(개요 우선), **노드 추가 시 그 노드만 펼침**(작성 동선).
  복수 동시 펼침 허용(엄격 아코디언 아님 — 노드 비교 편의).
- **펼침 상태는 UI 로컬**(인덱스 키) — 이동/삭제 시 키 재매핑. 저장 데이터 무변경.

## 완료 조건 (측정 가능)

1. 접기/펼치기 동작(e2e): 접으면 본문 컨트롤 사라지고 요약 노출, 펼치면 복원.
2. 요약 정확성(e2e): 모델·도구/문서 수·프롬프트 앞부분이 실제 설정과 일치, 설정 변경 후 접으면 갱신.
3. 노드 추가 → 새 노드 펼침·기존 접힘 유지(e2e).
4. 미완성 노드 접힘 헤더에 "작성 필요" 표시(e2e).
5. 헤더 클릭(이름 Input·버튼)이 접힘을 토글하지 않음 — 아이콘만(123 회귀).
6. 저장 payload 무변경(272/274 e2e 무회귀) + tsc 0 + 모바일 오버플로 0.
