## 변경

**① 순서(step ① 정체성)**: 이름·설명 → **에이전트 종류** → (종류별) 모델·페르소나 → 저장 방식.
블록 스왑만(노드형은 기존처럼 모델·페르소나 숨김 — 이제 종류 아래라 인과가 눈에 보임).

**② 비영속 기억 잠금 (실행 중 정정 — 사용자 확인 질문)**:
- 최초 지시는 "단기/장기 모두 잠금+제거"였으나, 사용자가 "비영속일 때도 최근 메시지 N개를 제공할
  수 있나? 오해한 것 같다"고 확인 질문 → **측정으로 답**: 단기(historyDepth)는 요청에 담겨 온
  `body.messages`를 자르는 실행 창(chat.py:1114 `_window`)이라 DB 저장과 무관 — **비영속에서도
  동작**(스펙 238의 원 결정이 옳았음). 장기(mem0)만 저장·회상이라 비영속과 진짜 충돌.
- 확정 설계: `setEphemeral(true)` = memwrite/memedit 해제 + **memories=[] 제거**(선택했는데 무동작
  함정 소거). **단기는 활성 유지** + hint로 "비영속에서도 요청에 담긴 대화에 적용" 안내.
- 장기 컨트롤은 기존 ephemeral 미선택-잠금 유지.

**③ 도구·승인·문서 = Collapse 하나에 아이템 3개(직접형 step ②) — 실행 중 사용자 재명세**:
- 1차 구현(한 패널에 세 구획을 다 넣음)을 사용자가 반려: 원한 것은 **`Collapse(Item, Item, Item)`**
  — 도구 아이템 / 승인 아이템(기본 부재·도구 선택 시 사이에 출현) / 문서 아이템. 별개 Collapse를
  쌓으면 뉴라인, 한 패널이면 구획 소실 — 형제 아이템이 정답(아코디언 그룹으로 밀착).
- ToolTree에 `bare` prop(Collapse 래퍼 없이 검색+트리만) — 도구 아이템의 children으로. 노드 카드·
  오버라이드는 기존 자체 Collapse 모드 유지.
- 승인 렌더러(toolPolicyRows/Body)를 함수로 추출 — 직접형=아이템(rows>0 시), 조율형·노드형=기존
  위치 독립 Collapse 유지(276 목록 규칙 그대로).
- doGroups(문서만 남았었음) 소멸 — 문서 아이템=체크박스 리스트(toggle('vectorTables') 재사용).
