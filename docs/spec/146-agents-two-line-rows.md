# 146 — 에이전트 리스트 2줄 행 + 라벨 교정 (실사용 피드백)

## 배경
사용자: '공유'(소유권)와 '공개'(A2A)가 헷갈림 → '공용'/'A2A 공개'로. 넓은 화면에서 행을
2줄로 — 1줄: 이름·페르소나·버전·A2A 공개·상태·액션(두 줄 걸침), 2줄: 공용/소유·소스·MCP·RAG.

## 설계
- 공유 DataTable에 `subRow` prop(스펙 146): 행=tbody(두 tr이 hover·클릭 한 몸), 보조 줄은
  액션 컬럼 뺀 전체 폭 colSpan, 액션은 rowSpan=2 세로 중앙. 모바일 카드에선 하단 태그 섹션.
- AgentsView: 소스·준수 컬럼 제거→보조 줄로 이사(+MCP·RAG 태그, RAG=vectorTables∪
  capabilities rag:). OwnerTag('공용')도 보조 줄로. 1줄 컬럼 폭 재배분.
- 준수 태그는 사용자 열거에 없었으나 정보 손실 방지 위해 보조 줄에 유지(불필요하면 제거).

## 검증
- 실측: 행당 tr 2·보조줄 태그 렌더·스크롤 diff 0(1400)·세션 표 회귀 0(1줄 유지). 스샷.
