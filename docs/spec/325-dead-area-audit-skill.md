## 설계

- **위치**: `.claude/skills/dead-area-audit/SKILL.md` (ui-audit 형식 미러 — frontmatter + 언제/실행/트리아지).

  시드·스키마/DB 고아) 병렬 위임 프롬프트(자기완결), 제외 목록, 증거·확신도 출력 형식.
- **규율(회고 299 반영)**: ①3급 분류(확실/유력/관찰) 후 제거는 **사용자 승인 별도** ②검증 실패는

  SELECT로 분포 확인 후 삭제, 스킬 자체는 읽기 전용까지만 지시 ⑤측정 완료선언은 값이 사는 모든
  장소 열거 후(agents vs agent_versions 교훈).
- **기준선**: 이전 감사의 "깨끗 확인"·"기각(오탐 방지)" 목록을 참조해 중복 보고를 줄인다 —
