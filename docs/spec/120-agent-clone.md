# 120 — 에이전트 복제 (저마찰 재사용)

## 배경 / 왜

플랫폼 핵심 가치 = **저마찰 생성 + 영속 재사용**(memory why-build-multi-agent-platform). "이거랑 비슷한
거 하나 더"가 가장 흔한 재사용·제일 저마찰인 생성 경로다. 방향 4(4개 방향 "모두 차례대로") 4번(마지막).
사용자 선택 "복제"(템플릿/프리셋 아님).

## 설계

- **백엔드** `POST /agents/{id}/clone` — 원본 설정을 새 **ui 초안**으로 복사:
  - 복제 = **읽기 + 새 생성** → 원본 *관리 권한 불요*(가시하면 복제 가능 — **사용≠관리**, 스펙 112를 새
    동사에 적용). 미존재/미가시 원본은 **404-fold**.
  - 소유권은 **복제자**에게 스탬프(원본 소유자 승계 금지 — 069 no-takeover). `owner_of(principal)`.
  - config는 행위 설정만 복사, **`card`(외부 등록 스냅샷) 제거**(endpoint/token은 Agent 컬럼이라 애초
    미복사 → 복제본은 안전한 ui 에이전트). 이름 = `{원본} (복사본)`. v1 draft 시딩(create와 동일 골격).
- **프론트**(admin) — `cloneAgent(id)` + 상세 드로어 "복제" 버튼. **복제는 관리 권한 불요라 can_manage
  게이트 밖에 항상 노출**(비소유 공유 에이전트도 복제 가능 = 재사용의 핵심). ui/code/external **세 상세
  드로어 모두**에 버튼(원격 에이전트의 행위 설정도 내 ui 초안으로 복사 — "놓친 렌더 지점" 방지, 스펙 114 교훈).

## 검증 (3런)

- **HTTP(verify_120)**: 복제 201·새 id·이름·source=ui·행위 config 복사(능력·impl·historyDepth·
  requires_approval·temperature)·`card` 미복사·복제자 can_manage·목록 독립·미존재 404-fold.
- **브라우저(shot-clone-120, 시스템 Chrome)**: 상세 드로어 "복제" 버튼 렌더 + 클릭→"(복사본)" 등장(배선).
  스크린샷으로 푸터 `복제 | 삭제 | 초안 편집` 시각 확인.
- **정적**: tsc 무오류. 무회귀 verify_110/117(채팅·A2A 경로 — clone 라우트 추가만).

## 비목표 (OUT)

- 템플릿/프리셋(미리 만든 시작점) — 사용자가 "복제" 선택. 필요 시 후속(백로그 씨앗).
- 딥 카피 옵션(버전 이력·활성 버전까지 복사) — 복제본은 v1 draft에서 새로 시작(깔끔한 출발).
- 원격(code/external) 복제 시 endpoint/token 승계 — 의도적 미복사(복제본=ui 행위 에이전트, 재등록 아님).
- 목록 행 인라인 복제 버튼 — 상세 드로어 버튼으로 충분(행 클릭→드로어가 자연 흐름). 필요 시 후속.
