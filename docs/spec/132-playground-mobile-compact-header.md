# 132 — 플레이그라운드 모바일 헤더: 여러 줄 스택 + 온전한 텍스트 (v2)

## 배경 / 왜
사용자(플레이그라운드 점검 2탄): "모바일 화면에서 에이전트와 세션, 각종 도구를 보여주는 것이 매우
답답합니다. 작은 아이콘으로만 표시." 현황 — 도구 버튼들은 compact(lg 미만)에서 이미 아이콘만이지만,
**AgentCombo**(아바타+이름+모델 배지+페르소나 2줄+초안 태그)와 **SessionCombo**(미리보기 텍스트
maxWidth 240)가 모바일(375~430px)에서 헤더를 가득 채워 답답.

## v1→v2 방향 수정 (사용자 실기기 피드백)
v1(아이콘만)을 실폰으로 써본 사용자 피드백: "에이전트를 선택해도 이름이 안 나옴 · 세션 이름 안 나옴 ·
버튼이 뭔지 안 보임 — **모바일이니까 여러 줄로, 온전한 텍스트로**." 아이콘만은 공간은 아꼈지만
**식별 정보를 없애** 답답함의 종류만 바꿨다. v2 = 세로 스택 + 전체 폭 + 라벨 표시.

## 설계 v2 (isMobile = !screens.md)
- 헤더를 **세로 스택 3줄**(auto 높이): 1줄 AgentCombo(전체 폭·이름/모델/페르소나 온전), 2줄
  SessionCombo(전체 폭·미리보기 라벨 온전), 3줄 도구 버튼(라벨 포함·flexWrap 줄바꿈).
- `iconOnly` → `fullWidth` prop으로 교체. compact(버튼 라벨 제거)는 **비모바일** 전용으로 한정.
- 드롭다운 `min(360/300px, 100vw-24px)` 캡은 유지(v1 산출물 중 존치).
- 데스크톱(md+) 무변경.

## 구 설계 v1 (폐기 — 기록용)
1. **AgentCombo `iconOnly`**: 트리거 = 아바타(+상태점)+드롭 화살표만(이름/모델/페르소나/초안 태그 숨김).
   드롭다운(피커)은 그대로 — 단 너비를 `min(360px, calc(100vw - 24px))`로 캡(화면 밖 넘침 방지).
2. **SessionCombo `iconOnly`**: 트리거 = 말풍선 아이콘+화살표만(라벨 숨김). 드롭다운 너비 동일 캡.
3. 도구 버튼(새 대화/오버라이드/시스템 프롬프트/인스펙터)은 기존 compact 규칙 유지(모바일 포함 —
   이미 아이콘만). 헤더 gap/padding 기존 모바일 축소값 유지.
4. 데스크톱(md+)은 무변경.

## 검증 (v2 기준)
- 브라우저(모바일 390×844): 헤더 3줄 스택 — 에이전트 **이름 표시**·세션 **라벨 표시**·도구 버튼
  **라벨 표시**, 피커/드롭다운 화면 내(boundingBox), 가로 오버플로 없음(scrollWidth ≤ 390).
- 데스크톱(1400) 무회귀: 한 줄 레이아웃 유지·이름/라벨 표시. tsc.
