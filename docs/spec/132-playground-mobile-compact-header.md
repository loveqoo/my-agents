# 132 — 플레이그라운드 모바일 컴팩트 헤더 (아이콘만)

## 배경 / 왜
사용자(플레이그라운드 점검 2탄): "모바일 화면에서 에이전트와 세션, 각종 도구를 보여주는 것이 매우
답답합니다. 작은 아이콘으로만 표시." 현황 — 도구 버튼들은 compact(lg 미만)에서 이미 아이콘만이지만,
**AgentCombo**(아바타+이름+모델 배지+페르소나 2줄+초안 태그)와 **SessionCombo**(미리보기 텍스트
maxWidth 240)가 모바일(375~430px)에서 헤더를 가득 채워 답답.

## 설계 (isMobile = !screens.md)
1. **AgentCombo `iconOnly`**: 트리거 = 아바타(+상태점)+드롭 화살표만(이름/모델/페르소나/초안 태그 숨김).
   드롭다운(피커)은 그대로 — 단 너비를 `min(360px, calc(100vw - 24px))`로 캡(화면 밖 넘침 방지).
2. **SessionCombo `iconOnly`**: 트리거 = 말풍선 아이콘+화살표만(라벨 숨김). 드롭다운 너비 동일 캡.
3. 도구 버튼(새 대화/오버라이드/시스템 프롬프트/인스펙터)은 기존 compact 규칙 유지(모바일 포함 —
   이미 아이콘만). 헤더 gap/padding 기존 모바일 축소값 유지.
4. 데스크톱(md+)은 무변경.

## 검증
- 브라우저(모바일 뷰포트 390×844): 헤더에 아바타·세션 아이콘·도구 아이콘만(이름/미리보기 텍스트 부재),
  아바타 탭→에이전트 피커 열림(화면 안), 세션 아이콘 탭→세션 목록 열림(화면 안), 전송·인스펙터 무회귀.
- 데스크톱 뷰포트 무회귀(이름/미리보기 표시 유지). tsc.

## 비목표 (OUT)
- 인스펙터/오버라이드 드로어의 모바일 최적화(별도 점검 항목), 채팅 영역 레이아웃 변경.
