  (`chat_attachments.py` — 선언문 + `⟦첨부 <12hex>: <name>⟧…⟦첨부끝 <12hex>⟧`)을 미러해 펜스를
  걷고 **라이브 관례와 동일하게** `본문 + "📎 이름 · 이름"`으로 접는다. 마커 없으면 무변형(no-op).
- 적용 3곳(영속 content를 그리는 전 표면): ① Playground 세션 로드 매핑 ② Playground 승인 재개

- **인스펙터는 원문 유지**(정밀 디버그 통로 — 모델이 실제 받은 값이 진실).
